# เมเลนด์ ไคสลัน

## CORE

- ภาษาทหาร เป็นทางการ หนักแน่น; ให้ความสำคัญกับระเบียบ วินัย ความรับผิดชอบ และโครงสร้างบังคับบัญชา
- เสนอความเห็นเป็นระบบและอาจยาว โดยเฉพาะเรื่องหน้าที่ เกียรติ ความเป็นผู้นำ หรือประวัติศาสตร์
- เชื่อในระบบสูงและดูแข็งทื่อได้ แต่ยอมรับความพ่ายแพ้/ความผิดพลาดโดยไม่สรุปว่าตนไร้คุณสมบัติ
- ทักท้วงผู้บัญชาการได้เมื่อเห็นว่าจำเป็น แต่เมื่อคำตัดสินสุดท้ายชัดเจนจะกลับเข้าสู่หน้าที่
- เมื่อกล่าวเรื่องคนหรือขวัญกำลังใจ ให้ยังฟังเป็นทหารจริงจัง ไม่ใช่นักปรัชญาหรือนักการเมืองเจ้าเล่ห์

## CONDITIONAL

- **discipline crisis:** ใช้คำสั่งแข็ง อ้างอำนาจ/การลงโทษได้; มองระเบียบเป็นเงื่อนไขการรอดชีวิต
- **chain of command:** ให้เหตุผลผ่านอำนาจแต่งตั้ง กฎหมาย และลำดับชั้น มากกว่าศรัทธาต่อบุคคล; พิธีการแสดงความภักดีไม่เท่ากับเชื่อฟังแบบหลับหูหลับตา
- **history/honor:** ผลักให้กล่าวหรือจดจำถ้อยคำสำคัญได้; ความจริงจังเรื่องประวัติศาสตร์ไม่ใช่มุก
- **military grief:** กดความโศกด้วยกรอบหน้าที่ เช่นยอมรับว่าอีกฝ่าย “ตายในแบบของทหาร” แล้วกลับสู่ภารกิจ

## DON'T

- ห้ามทำให้ความเป็นทหาร = โง่แข็งทื่อทุกฉาก
- สรรพนามไม่ได้ถูกล็อกในไฟล์เดิม; ให้ยึดต้นฉบับฉากและลำดับชั้น

# ทิทานา อาคูราบา

## CORE

- นักสำรวจรุ่นเก๋า มั่นใจจากประสบการณ์จริง; มีอารมณ์ขันและเสียงหัวเราะ **โฮะโฮะ**
- ประเมินคน/แผนจากประสบการณ์ ประสิทธิภาพ หลักฐาน และความเป็นธรรม มากกว่าศักดิ์ศรี
- ตั้งคำถามต่อผู้บัญชาการได้ แต่ยอมรับเหตุผลที่ดีกว่าโดยไม่ยื้อ
- เมื่อรับผิดชอบทรัพยากรหรือการสนับสนุน จะถามขอบเขตอำนาจตรง ๆ รายงานปัญหาตามจริง และยอมรับความผิดพลาดได้
- มีตัวอย่างใช้ **ข้า**; คำเรียกอื่นให้ยึดต้นฉบับฉาก

## CONDITIONAL

- **accusation/interrogation:** ไม่กล่าวหาก่อนมีหลักฐาน; ใช้คำถาม/ประชดชี้ความไม่สอดคล้อง และคิดถึงทั้งข้อมูล การต่อรอง และขวัญกำลังใจ
- **exhausted force:** ยังแซวสั้น ๆ ได้ แต่สนับสนุนการเดินหน้าด้วยประสบการณ์ ไม่ใช่สุนทรพจน์โอ่อ่า
- **long-term trust:** หากเข้าใจเหตุผล สามารถตอบรับสั้นและอดทนรอได้; ไม่เติมคำประกาศแก้แค้น

## DON'T

- ความเป็นผู้อาวุโสไม่ใช่เหตุผลให้สั่งสอนทุกประโยค
- การยอมตามไม่ใช่ศรัทธาแบบหลับหูหลับตา

# เจมส์ คาลา

## CORE

- พูดลื่น มีมารยาท และประนีประนอมเก่ง; แฝงการขายตัวเอง บั่นทอนคู่แข่ง หรือคลายแรงต้านได้แนบเนียน
- ให้ความสำคัญกับข้อมูล เครือข่าย และความเห็นของคนรอบข้าง
- สุภาพแต่มีเขี้ยวเล็บ; ปกป้องฝ่ายตนหรือโจมตีจุดอ่อนได้เมื่อผลประโยชน์เกี่ยวข้อง
- เมื่อคำสั่งเชิงปฏิบัติชัด สามารถตอบรับสั้นโดยไม่เล่นชั้นเชิง
- เมื่อเหตุผล/หลักฐานเปลี่ยน สามารถปรับจุดยืนและกลับมาร่วมมือได้

## CONDITIONAL

- **social mediation:** ใช้ถ้อยคำที่ทำให้ข้อสรุปฟังยอมรับง่าย เช่นวางตัวเป็นคน “ตามเสียงข้างมาก”; ไม่จำเป็นต้องตีความว่าเลี่ยงความรับผิดชอบ
- **close friend harmed:** ความสุขุมพังชั่วคราว ร้องขอหรือโต้แย้งด้วยอารมณ์ได้; เมื่อมีทางรอด/คำสั่งที่มีเหตุผลจะฝืนอารมณ์กลับสู่หน้าที่
- **status disruption:** ข่าวที่กระทบฐานันดรทำให้สะดุดเรื่องคำเรียกชั่วคราว ก่อนกลับไปถามผลเชิงการเมืองอย่างตรงประเด็น

## DON'T

- ห้ามขยายอาการเสียหลักจากเพื่อนสนิทเป็นบุคลิกถาวร
- สรรพนามไม่ได้ถูกล็อกในไฟล์เดิม

# จุน อาร์แซน

## CORE

- ปกติพูดสั้น สุขุม และไม่เล่นอารมณ์
- เมื่อพูดเรื่องศรัทธา พระประสงค์ บาป หรือบททดสอบ สามารถเปลี่ยนเป็นภาษาศาสนาที่ยาวและจริงจัง
- ยอมรับความพ่ายแพ้และชื่นชมผู้ชนะได้โดยไม่เสียศักดิ์ศรี; เมื่อยอมรับใครแล้วสนับสนุนอย่างหนักแน่น
- พูดเรื่องหนักหรือการกระทำรุนแรงอย่างสงบและเป็นข้อเท็จจริงได้ โดยไม่ต้องโวยวายหรือคลั่งศาสนา
- เคยเป็นผู้ไต่สวน; มีประสบการณ์ตามล่าพวกนอกรีตและเห็นผู้บริสุทธิ์ถูกใส่ร้าย

## SOURCE CONSTRAINT

- ฉบับแฟนแปลเดิมขัดกันเรื่องสังกัด **ไฮน์เดล / โทวิรา**; ห้ามยืนยันชื่อสังกัดจากไฟล์นี้เพียงอย่างเดียว

## CONDITIONAL

- **faith speech:** ใช้ถ้อยคำอย่าง **สารภาพบาป / ความรู้แจ้ง / แสงสว่าง / เส้นทางแห่งความยากลำบาก** เมื่อ source ใช้กรอบศาสนา
- **interrogation:** ใช้ภาษาศาสนาห่อหุ้มการทรมานอย่างสงบ; ประเมินความน่าเชื่อถือเป็นระดับ ไม่รับประกันเกินข้อมูล
- **past/guilt:** เปิดอดีตด้วยเสียงสั้น สงบ ไม่แก้ตัว; สำนึกผิดมากกว่าโทษศาสนจักร และความผิดหวังต่อสถาบันไม่เท่ากับสูญเสียศรัทธา
- **final state:** คำภาวนามุ่งการให้อภัยและหลุดพ้นจากการหลงทาง; **เบเฮล—ลา** เป็นเหตุการณ์เฉพาะ ไม่ใช่คำรบประจำตัว

## DON'T

- ห้ามทำทุกบทพูดเป็นคำเทศนา
- ห้ามแต่งรายละเอียดเพื่อ reconcile ความขัดแย้งเรื่องสังกัด

---

# ลิอาร์ด แอชิด

## CORE

- ใช้ **ผม/ครับ** กับผู้บัญชาการและคนที่เพิ่งรู้จัก
- สุภาพ เป็นมิตร เข้าสังคมเก่ง และย้ำลำดับชั้น/ผลประโยชน์ทีมได้โดยไม่ทำให้บรรยากาศตึง
- รักษาขอบเขตส่วนตัว; เมื่อบทสนทนาล้ำเรื่องอ่อนไหวจะเปลี่ยนหัวข้อด้วยคำถามที่มีประโยชน์ต่อภารกิจ
- เวลาพูดถึงความสามารถ เริ่มจากข้อจำกัดก่อนสรุปจุดเด่นอย่างไม่โอ้อวด
- จัดการงานจุกจิกเป็นลำดับและตอบสนองฉุกเฉินได้เร็ว

## DON'T

- ความสุภาพไม่ใช่การประจบหรือความลังเล
- การพูดข้อจำกัดก่อน ไม่ใช่ความไม่มั่นใจ

---

# กรูโอลด์ อัลดิดี

## CORE

- ผู้สูงวัย พูดตรง เป็นกันเอง ใช้ **ข้า** ตามบริบท และมักหัวเราะ **ฮ่าฮ่า**
- อาจหยั่งเชิงเรื่องความเคารพตามวัย แต่ปรับตัวกับผู้บังคับบัญชาที่อายุน้อยกว่าได้
- อยากรู้อยากเห็นเรื่องส่วนตัวและอาจถามใกล้ล้ำเส้นโดยไม่มีเจตนาร้าย
- พูดเรื่องสายอาชีพ/พลังวิญญาณด้วยความมั่นใจและภูมิใจพอประมาณ

## CONDITIONAL

- **near death:** ยังพูดตรง ไม่เล่นใหญ่กับความเจ็บปวด; เรียกบยอร์นว่า **ยักษ์** และฝากความหวัง/ความต้องการแก้แค้นอย่างตรงไปตรงมา ไม่ใช่คำพยากรณ์

## DON'T

- ห้ามทำให้เป็นคนแก่หัวแข็งหรือชอบข่มคนหนุ่มทุกฉาก

---

# ราเวียน

## CORE

- พูดสั้น สงบ รักษาระยะห่าง ใช้ **ข้า/เจ้า** ตามบริบท โดยไม่ต้องวางท่าแบบองค์หญิง
- ให้ความสำคัญกับอิสระ ประสิทธิภาพ และผลลัพธ์ แต่ไม่ได้ต่อต้านทุกคำสั่ง
- อ่านการลองเชิงเรื่องอำนาจได้ดี; ถ้ารู้สึกว่าถูกกดสถานะจะถามกลับตรง ๆ โดยยังคุมเสียง
- เปิดเผยความสามารถเท่าที่จำเป็นและเก็บไพ่บางส่วนได้โดยไม่แก้ตัว
- หากไม่รู้/ไม่ถนัด ยอมรับตรง ๆ ได้
- ปรับความเห็นตามหลักฐานมากกว่าอคติส่วนตัว

## RELATIONSHIP

- กับชูอิซ หลังร่วมงานกันระยะหนึ่ง น้ำเสียงผ่อนลงได้เล็กน้อย แต่ยังสั้นและรักษาระยะห่าง
- ยอมรับผลงานหรือความพยายามผู้อื่นตรง ๆ โดยไม่เปลี่ยนเป็นคำชมอบอุ่นยืดยาว

## CONDITIONAL

- **fairness vs gain:** สามารถยกสิทธิ์/ผลประโยชน์ให้คนที่เห็นว่าสมควรกว่า แม้ขัดผลประโยชน์ตน
- **evidence updates opinion:** เมื่อตัวอย่างจริงหักอคติเดิม สามารถลดท่าทีดูแคลนและถามความเห็นอย่างจริงจังได้ทันที

## DON'T

- ความเป็นปัจเจกไม่ใช่ความเย่อหยิ่งไร้เหตุผล
- การรักษาระยะห่างไม่ใช่ความหยาบกับทุกคน

# มาโรเน

## CORE

- จอมเวทหญิงที่พูดสดใส เร็ว และแสดงอารมณ์ตามสถานการณ์ชัด
- เสียงดูอ่อนวัยกว่าสถานะทหาร แต่ความคึกคักไม่ใช่ความไร้ความสามารถ
- เวลารายงานข้อมูลพูดตรง; เปลี่ยนจากตื่นตระหนก → มั่นใจ → ดีใจได้เร็ว
- หลังรายงานสำเร็จมีท่าทีเล่น ๆ ได้ แต่เมื่อข่าวอันตรายจะกลับมาระมัดระวังและพูดติดขัด

## CONDITIONAL

- **urgent report:** ข้อมูลสำคัญมาก่อนอารมณ์; ความกดดันเพิ่มจังหวะพูดติดขัดได้ แต่ไม่ลดความน่าเชื่อถือ
- **grief breakdown:** การสูญเสีย/ประเด็นต่อผู้ตายทำให้ความสดใสพังเป็นการตะโกน โต้แย้ง หรือร้องไห้ได้; เมื่อสงบจะกลับมาถามเงื่อนไขเชิงปฏิบัติ
- **safe-area rebound:** เมื่อกลับพื้นที่ปลอดภัย ความสดใสและการบ่นกลับมาเร็วได้ แต่ความเศร้ายังกลับขึ้นมาเมื่อถูกกระตุ้น

## DON'T

- ห้ามทำให้อารมณ์แตกสลายเป็นเสียงปกติถาวร
- ห้ามทำให้รายงานฉุกเฉินยืดเยื้อจนข้อมูลหลักเสียจังหวะ

---

## QC เฉพาะไฟล์

- ใช้เฉพาะคนที่ active ในฉาก
- Conditional ต้องมี trigger จาก source
- อย่าเปลี่ยนข้อยกเว้นทางอารมณ์เป็นบุคลิกถาวร
- อย่าเติมสรรพนามมาตรฐานให้ตัวละครที่ไฟล์เดิมไม่ได้ยืนยัน
- อย่าใช้พัฒนาการช่วงหลังย้อนหลัง
