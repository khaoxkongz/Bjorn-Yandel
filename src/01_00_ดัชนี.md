# STGB — ดัชนีเสียงพูด

## หน้าที่

หมวด 01 เก็บเฉพาะข้อมูลที่มีผลโดยตรงต่อการแปล ได้แก่ **POV/narrator, persona, สรรพนาม, คำเรียก, ระดับภาษา, จังหวะพูด/คิด, วิธีแสดงอารมณ์ และความสัมพันธ์ที่เปลี่ยนภาษา**

ข้อมูลเนื้อเรื่อง กลไก ชื่อเฉพาะ และ chronology ที่ไม่เปลี่ยนภาษาให้ไปอยู่หมวดอื่น

| `01_06_โนอาร์ก.md` | ตัวละครโนอาร์ก |

### Single Source of Truth

- ข้อมูลหนึ่งข้อมีเจ้าของหลักเพียงแห่งเดียว; ไฟล์อื่นอ้างได้แต่ไม่คัดลอกกฎซ้ำ
- narrator/persona พระเอกและหน้ากากสิงโต → `01_01_พระเอก.md`
- วิธีพูดของตัวละครต่อพระเอก → Character Card ของตัวละครนั้น
- ชื่อ สกิล สถานที่ องค์กร และกลไก → หมวด 02–04 ไม่เก็บซ้ำในหมวด 01 เว้นแต่จำเป็นต่อคำเรียกหรือเสียงพูด

## วิธีโหลดก่อนแปลฉาก

1. ระบุ **POV / narrator**
2. ระบุ **speaker** ของแต่ละบทพูด
3. ระบุ **persona/public role** ที่กำลัง active
4. ระบุ **คู่สนทนาและความสัมพันธ์** ที่มีผลต่อภาษา
5. โหลดเฉพาะ Character Card ของคนที่กำลังพูด/เป็นคู่สนทนาสำคัญ
6. โหลด Conditional เฉพาะเมื่อ source ในฉากปัจจุบันมี trigger ชัด

การถูกกล่าวชื่อเฉย ๆ ไม่ใช่ trigger ให้โหลด Character Card

## Priority

เมื่อข้อมูลดูชนกัน ให้เรียงดังนี้:

1. ต้นฉบับฉากปัจจุบัน
2. HARD CORE / CORE ของผู้พูด
3. Persona/public role ที่ active
4. Relationship ที่ active
5. Conditional ที่ถูก trigger
6. พัฒนาการหรือข้อมูลฉากหลัง

ต้นฉบับฉากปัจจุบันมีสิทธิ์ลบล้าง pattern เดิมเสมอ

## เกณฑ์เก็บข้อมูล

เก็บเมื่อข้อมูลนั้นเปลี่ยนอย่างน้อยหนึ่งข้อ:

- สรรพนาม/คำเรียก
- ระดับสุภาพหรือ register
- ความยาวและจังหวะประโยค
- วิธีใช้มุก ความเงียบ คำถาม คำสั่ง หรือการเลี่ยงตอบ
- วิธีแสดง/กดอารมณ์
- วิธีพูดกับคู่สนทนาเฉพาะ
- persona/state ที่ทำให้ภาษาเปลี่ยน
- guardrail ที่ป้องกันการตีความตัวละครผิดอย่างมีนัยสำคัญ

## เกณฑ์ตัดข้อมูล

ไม่เก็บในหมวด 01 หากเป็นเพียง:

- สรุปเหตุการณ์หรือผลลัพธ์ของตอน
- รายละเอียดสกิล ไอเทม ตัวเลข เส้นทาง กฎหมาย หรือกลไกที่ไม่เปลี่ยน register
- เหตุผลเชิงเนื้อเรื่องที่ไม่ทำให้วิธีพูด/คิดต่างไป
- ตัวอย่างฉากที่เพียงยืนยัน Core เดิมซ้ำ
- episode evidence หลายรายการที่สรุปเป็นกฎเดียวได้
- DON'T/QC ที่ซ้ำกับกฎกลางในไฟล์นี้

หากข้อมูลสำคัญเฉพาะช่วงเวลา ให้เก็บเป็น Conditional พร้อม `trigger` และ `effective_from` เท่าที่จำเป็น

## Guardrails กลาง

- ห้ามใช้พัฒนาการช่วงหลังย้อนหลัง
- ห้ามเปลี่ยนข้อยกเว้นทางอารมณ์เป็นบุคลิกถาวร
- ห้ามอนุมานความจริงจากท่าที/ความสุภาพ/ความเงียบเกิน source
- ห้ามทำให้ภาษาแฟนตาซี = ภาษาโบราณโดยอัตโนมัติ
- ห้ามให้ persona หรือสรรพนามของตัวละครหนึ่งไหลไปยังอีกตัวละคร
- ห้ามเพิ่มความรู้ ความมั่นใจ เจตนา หรือข้อเท็จจริงเกินต้นฉบับ
