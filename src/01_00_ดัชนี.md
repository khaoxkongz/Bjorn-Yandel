# STGB — ดัชนีเสียงพูด

## หน้าที่

หมวด 01 เก็บเฉพาะข้อมูลที่มีผลต่อ **เสียงคิด เสียงพูด สรรพนาม คำเรียก จังหวะภาษา และการแสดงอารมณ์ผ่านภาษา**

หมวดนี้ **ไม่ใช่คลัง continuity หรือสรุปเนื้อเรื่อง**

หมวด 01 ไม่ควรเก็บ:

- เหตุการณ์ที่ตัวละครเพิ่งทำ หากไม่เปลี่ยนวิธีพูด
- เป้าหมายหรือแผนปัจจุบัน
- สถานที่ปัจจุบัน
- ความลับหรือข้อมูลที่ตัวละครเพิ่งรู้
- รายละเอียดการต่อสู้ที่ไม่ส่งผลต่อเสียง
- ประวัติเนื้อเรื่องที่สามารถตัดออกได้โดยไม่กระทบการเลือกคำ

กฎการแปลระดับโปรเจ็กต์ให้ยึด `00_ดัชนี.md` เป็นเจ้าของ ไม่ทำสำเนาไว้ในหมวด 01

### Single Source of Truth

- ข้อมูลหนึ่งข้อมีเจ้าของหลักเพียงแห่งเดียว
- ไฟล์อื่นอ้างถึงเจ้าของได้ แต่ไม่คัดลอกกฎซ้ำ
- narrator identity / persona พระเอก → `01_01_พระเอก.md`
- หน้ากากสิงโต → `01_01_พระเอก.md` เท่านั้น
- ความสัมพันธ์เฉพาะกับตัวละครอื่น → Character Card ของตัวละครนั้นเป็นเจ้าของวิธีพูดของตนเอง

## Priority

เมื่อข้อมูลดูเหมือนชนกัน ให้ใช้ลำดับนี้:

1. ต้นฉบับ **ฉากปัจจุบัน**
2. HARD CORE / CORE ของผู้พูด
3. Persona ที่ source ยืนยันว่ากำลังใช้
4. Relationship ของคู่สนทนาที่ active
5. Conditional ที่ source trigger
6. พัฒนาการเก่า/ข้อมูลฉากหลัง

Conditional ห้ามลบล้างสิ่งที่ต้นฉบับฉากปัจจุบันแสดงชัด

---

## Scene-Gated Loading

### 1. อ่านฉากก่อน Context

ระบุ:

- POV / narrator
- ใครพูดจริง
- พระเอกใช้ persona ใด
- มี trigger พิเศษอะไรหรือไม่

### 2. โหลดเฉพาะไฟล์ที่เกี่ยวข้อง

- พระเอก active → `01_01_พระเอก.md`
- พวกพ้อง active → `01_02_พวกพ้องพระเอก.md`
- แคลนอานาบาดา active → `01_03_แคลนอานาบาดา.md`
- ตัวละครทั่วไป/ขุนนาง active → `01_04_ทั่วไป.md`
- โต๊ะกลม active → `01_05_ผู้เฝ้ามองแห่งโต๊ะกลม.md`
- โนอาร์ก active → `01_06_โนอาร์ก.md`

**ห้าม preload หมวด 01 ทุกไฟล์พร้อมกัน**

### 3. จำกัดระดับ Character

ใช้เฉพาะ Character Card ของคนที่:

- กำลังพูด
- เป็นคู่สนทนาที่ความสัมพันธ์มีผลต่อภาษา
- หรือเป็นศูนย์กลางอารมณ์ของฉากตามต้นฉบับ

การถูกกล่าวชื่อเฉย ๆ ไม่ใช่ trigger

### 4. Conditional

Conditional ต้องมี trigger ชัดเจน **ในชื่อรายการหรือบรรทัด `trigger`** และใช้เฉพาะเมื่อ source รองรับ

ตัวอย่างสิ่งที่ต้อง gate:

- trauma / grief / fear / anger
- commander mode
- public role / false identity
- persona หน้ากากสิงโต
- พฤติกรรมหลังข้ามเวลา
- พัฒนาการเฉพาะช่วงเรื่อง

## สิ่งที่ควรเก็บในหมวด 01

เก็บเมื่อข้อมูลนั้นเปลี่ยนอย่างน้อยหนึ่งอย่าง:

- สรรพนามหรือคำเรียก
- ระดับสุภาพ
- จังหวะพูด/คิด
- วิธีแสดงอารมณ์
- วิธีตอบสนองต่อคู่สนทนา
- persona หรือ state ที่เปลี่ยนการใช้ภาษา

หากเหตุการณ์ไม่เปลี่ยนสิ่งเหล่านี้ → ไม่เก็บในหมวด 01  
หากเปลี่ยนเฉพาะบางเงื่อนไข → แปลงเป็น Conditional Capsule  
หากกลายเป็นลักษณะคงที่ → สรุปเข้า Core แล้วตัด chronology ออก

## QC ข้ามไฟล์

ก่อนส่งบทแปล ตรวจว่า:

1. narrator identity ถูกหรือไม่
2. สรรพนาม/คำเรียกมาจากเจ้าของข้อมูลที่ถูกต้องหรือไม่
3. persona ภายนอกไหลเข้า inner narration หรือไม่
4. มี Character Card ของคนที่ไม่ active เข้ามาปนหรือไม่
5. Conditional ถูกใช้โดยไม่มี trigger หรือไม่
6. มีพัฒนาการช่วงหลังรั่วไปใช้ย้อนหลังหรือไม่
7. มีข้อมูลเดียวกันถูกกำหนดซ้ำจากหลายไฟล์หรือไม่
