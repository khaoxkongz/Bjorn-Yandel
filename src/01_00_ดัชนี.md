# STGB — ดัชนีเสียงพูด

## หน้าที่

หมวด 01 เก็บเฉพาะข้อมูลที่มีผลโดยตรงต่อการแปล ได้แก่ **POV/narrator, persona, สรรพนาม, คำเรียก, ระดับภาษา, จังหวะพูด/คิด, วิธีแสดงอารมณ์ และความสัมพันธ์ที่เปลี่ยนภาษา**

## Ownership

| ไฟล์ | เจ้าของข้อมูล |
| --- | --- |
| `01_00_ดัชนี.md` | routing, priority, scene gating, retention rules |
| `01_01_พระเอก.md` | narrator identity อีฮันซู + persona พระเอกทั้งหมด รวมหน้ากากสิงโต |
| `01_02_พวกพ้องพระเอก.md` | พวกพ้องใกล้ชิดพระเอก |
| `01_03_แคลนอานาบาดา.md` | ตัวละครแคลนอานาบาดา |
| `01_04_ทั่วไป.md` | ฮยอนบยอล ขุนนาง คนรู้จักเก่า และตัวละครทั่วไป |
| `01_05_ผู้เฝ้ามองแห่งโต๊ะกลม.md` | สมาชิกโต๊ะกลม ยกเว้นหน้ากากสิงโต |
| `01_06_โนอาร์ก.md` | ตัวละครโนอาร์ก |

## Considerations

1. ระบุ **POV / narrator**
2. ระบุ **speaker** ของแต่ละบทพูด
3. ระบุ **persona/public role** ที่กำลัง active
4. ระบุ **คู่สนทนาและความสัมพันธ์** ที่มีผลต่อภาษา
5. ระบุ Character Card ของคนที่กำลังพูด/เป็นคู่สนทนาสำคัญ

## Priority

เมื่อข้อมูลดูชนกัน ให้เรียงดังนี้:

1. ต้นฉบับฉากปัจจุบัน
2. HARD CORE / CORE ของผู้พูด
3. Persona/public role ที่ active
4. Relationship ที่ active
5. Conditional ที่ถูก trigger
6. พัฒนาการหรือข้อมูลฉากหลัง

ต้นฉบับฉากปัจจุบันมีสิทธิ์ลบล้าง pattern เดิมเสมอ
