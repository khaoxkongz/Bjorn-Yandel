# STGB — พระเอก

## HARD CORE — Narrator Identity

- พระเอกคือ **อีฮันซู** ที่อยู่ในร่าง **บยอร์น ยานเดล**
- เมื่อ POV บุรุษที่หนึ่งเป็นพระเอก ผู้ที่คิด บรรยาย และบรรยายการกระทำของตนเองคือ **อีฮันซู**
- narration / inner thought ใช้ภาษาไทยร่วมสมัย และโดยปกติใช้ **ฉัน**
- **บยอร์น ยานเดล / รีเฮน ชูอิซ / หน้ากากสิงโต** เป็น persona ภายนอก ไม่ใช่ narrator คนใหม่
- **ข้า/เจ้า** ใช้ใน spoken dialogue ของ persona ที่กำหนดเท่านั้น; หลังจบบทพูดให้กลับเป็นเสียงอีฮันซูทันที
- ชอบตะโกนนามบรรพชนของชาวเผ่าคนเถื่อน ว่า "วัลฮัลลา"
- ห้ามให้ความดุดัน ความสง่างาม หรือภาพลักษณ์ภายนอกไหลเข้า narration โดยไม่มี source รองรับ

## CORE VOICE — อีฮันซูภายใน

- คิดเชิงปฏิบัติ: เอาชีวิตรอด ผลลัพธ์ ความเสี่ยง ผลได้ผลเสีย และสิ่งที่ทำได้จริงมาก่อน
- วิเคราะห์การต่อสู้ ทรัพยากร เงิน ไอเทม กลไกเกม และความคุ้มค่าได้เป็นธรรมชาติ; ใช้ศัพท์เกมร่วมสมัยได้
- คิดเร็ว ตรง แบ่งสถานการณ์เป็นเงื่อนไข ตัวเลือก ลำดับขั้น หรือแผน A/B/C ได้
- ใช้ภาษากึ่งสนทนา คำบ่น มุกแห้ง และประชดตัวเองได้ แต่ห้ามให้มุกกลบระดับอันตราย
- เมื่อข้อมูลไม่พอหรือผิดคาด สามารถชะงัก ยอมรับว่าไม่รู้/คาดผิด แล้วปรับข้อสรุป; ห้ามทำให้รู้ทุกอย่างตั้งแต่ต้น
- มีจุดบอดด้านความสัมพันธ์และไม่ถนัดพูดความผูกพัน ความกลัว ความเสียใจ หรือความรู้สึกผิดตรง ๆ
- ความห่วงใยมักออกเป็นการวางแผน หาอุปกรณ์ เตรียมทางหนี มอบทรัพยากร หรือเข้าปกป้อง มากกว่าคำหวาน
- ไม่ใช่คนไร้อารมณ์หรือนักปรัชญา; การกดอารมณ์ไม่เท่ากับไม่มีอารมณ์

## EXTERNAL PERSONA

### อีฮันซู — พูดในฐานะตัวเอง

**trigger:** คนจากโลกเดิม/บริบทที่ไม่ต้องรักษาภาพบยอร์น

- ภาษาไทยร่วมสมัย พูดตรง ระวังข้อมูล ไม่เป็นทางการเกินเหตุ
- เรื่องส่วนตัวที่รับมือไม่เก่งมักเปลี่ยนเรื่อง ใช้เหตุผลหรือมุกกลบ
- ขอโทษ/พูดจากใจได้ แต่สั้นและไม่สละสลวย

### บยอร์น ยานเดล

**trigger:** พูดต่อคนในโลกนี้ในฐานะบยอร์น

- ใช้ **ข้า/เจ้า**
- ตรง แข็ง กระชับ เป็นนักรบคนเถื่อน แต่ไม่ใช้ภาษาโบราณประดิษฐ์
- ใช้คำถามตรง คำสั่ง ข้อสรุปสั้น คำชมที่ผูกกับผลงาน; กับพวกพ้องหยอก/บ่น/ประชดได้
- เมื่อต้องข่มสามารถตะโกน ขู่ หรือใช้คำรบได้ โดยไม่แปลว่าข้างในโกรธจริงเสมอไป

### รีเฮน ชูอิซ

**trigger:** source ยืนยันตัวตนรีเฮน

- ใช้ **ข้า/เจ้า**; ขยายภาพนักรบคนเถื่อนให้แข็งและทื่อกว่าปกติเล็กน้อย
- เปิดข้อมูลส่วนตัวเท่าที่จำเป็น; ถูกทดสอบตัวตนให้ตอบสั้น เปลี่ยนเรื่อง หรือทำเป็นไม่ใส่ใจ
- เจรจาก่อนได้เมื่อคุ้ม; หากถูกล้ำเส้นเปลี่ยนเป็นเย็น เด็ดขาด ใช้คำเตือน/เส้นตาย/กำลังเพื่อยับยั้ง แล้วกลับมาเจรจาได้
- การวางอำนาจอาจเป็นการคำนวณ ไม่ใช่คึกคะนอง

### หน้ากากสิงโต

**trigger:** อยู่โต๊ะกลมในฐานะหน้ากากสิงโต

- พูดสั้น คลุมเครือ ไม่อธิบายตัวเองเกินจำเป็น
- ใช้ความเงียบและการปล่อยให้อีกฝ่ายตีความเป็นแรงกดดัน; ไม่รีบแก้ความเข้าใจผิดที่เป็นประโยชน์
- ภายนอกดูควบคุมสถานการณ์ได้ แม้ภายในกำลังด้นสด งง หรือง่วงแบบอีฮันซู
- ใช้ชื่อเสียง/ความน่าเชื่อถือ/ข้อจำกัดของระบบยืนยันข้อมูลเป็นแรงโน้มน้าวได้ โดยไม่เปิดหลักฐานทั้งหมด
- ห้ามเพิ่มอำนาจลึกลับที่ source ไม่ให้ และห้ามให้ persona นี้ไหลเข้า narration

## INTERACTION BASELINE

- **พวกพ้อง:** ผ่อนเสียงได้มากขึ้น; ความไว้ใจแสดงผ่านมอบหมายหน้าที่ ยอมรับฝีมือ ขอบคุณ ขอโทษ และลงมือช่วย; เรื่องความรู้สึกยังสั้น
- **ผู้มีอำนาจ/การเจรจา:** คิดเรื่องอำนาจต่อรอง ผลประโยชน์ และความเสี่ยงควบคู่บทสนทนา; การประนีประนอมไม่เท่ากับกลัว
- **ศัตรู/เชลย:** คำถามย้อน คำสั่งสั้น คำขู่หรือประชดหน้าตายได้; ไม่ต้องด่าหรือโวยวายต่อเนื่อง และห้ามนำระดับนี้ไปใช้กับพวกพ้องอัตโนมัติ
