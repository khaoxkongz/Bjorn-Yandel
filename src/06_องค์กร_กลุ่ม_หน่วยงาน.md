# STGB — องค์กร กลุ่ม และหน่วยงาน

## องค์กร

เก็บ **องค์กรหรือสถาบันที่มีตัวตนค่อนข้างถาวร** เช่น แคลน บริษัท กิลด์ ศาสนจักร และสำนัก หน่วยปฏิบัติการของรัฐ/ทหารให้เก็บใน `หน่วยงาน` ส่วนฝ่าย เผ่า ชุมชน หรือกลุ่มเฉพาะให้เก็บใน `กลุ่ม`

| อังกฤษ                 | ไทย           |
| ---------------------- | ------------- |
| Ghostbusters           | โกสต์บัสเตอร์ |
| Orcules                | ออร์คิวลิส    |
| Anabada Clan / Anabada | แคลนอานาบาดา  |

## กลุ่ม

เก็บ **ฝ่าย เผ่า ครอบครัว ชุมชน ห้องแชต และกลุ่มเฉพาะ** ที่ไม่ใช่องค์กรถาวรหรือหน่วยราชการ/ทหาร องค์กรถาวรให้เก็บใน `องค์กร` และหน่วยปฏิบัติการให้เก็บใน `หน่วยงาน`

| อังกฤษ                        | ไทย                   |
| ----------------------------- | --------------------- |
| Fairy Tribe                   | เผ่าแฟรี่             |
| Long Live Korean Independence | แด่อิสระภาพของเกาหลี  |
| Watchers of the Round Table   | ผู้เฝ้ามองแห่งโต๊ะกลม |
| Melbeth                       | เมลเบธ                |

## หน่วยงาน

เก็บ **หน่วยราชการ หน่วยบริหาร หน่วยทหาร และหน่วยเฉพาะกิจ** รวมถึงสภาหรือสำนักงานที่ทำหน้าที่เป็นหน่วยงาน องค์กรถาวรภาคเอกชน/ศาสนา/แคลนให้เก็บใน `องค์กร`

| อังกฤษ  | ไทย     |
| ------- | ------- |
| Mozelan | โมเซลัน |
