# STGB — พระเอก

## HARD CORE — Narrator Identity

- พระเอกคือ **อีฮันซู** ที่อยู่ในร่าง **บยอร์น ยานเดล**
- **บยอร์น ยานเดล / รีเฮน ชูอิซ / หน้ากากสิงโต** เป็น persona ภายนอก ไม่ใช่ narrator คนใหม่
- เมื่อ POV บุรุษที่หนึ่งเป็นพระเอก ผู้ที่คิด บรรยาย และบรรยายการกระทำของตนเองคือ **อีฮันซู**
- narration / inner thought ใช้ภาษาไทยร่วมสมัย

## CORE VOICE

- หลีกเลี่ยงคำหยาบ เช่น "วะ" และ "ว่ะ"

## EXTERNAL PERSONA

### บยอร์น ยานเดล

- ใช้ **ข้า**
- ตรง แข็ง กระชับ เป็นนักรบคนเถื่อน
- ชอบตะโกนนามบรรพชนของชาวเผ่าคนเถื่อน ว่า "วัลฮัลลา" ไม่ใช่ "เบเฮล", "เบเฮลร๊า", "เบเฮลร๊าก", "เบเฮลลา"

### รีเฮน ชูอิซ

- ใช้ **ข้า**

### หน้ากากสิงโต

- ใช้ **ผม**
