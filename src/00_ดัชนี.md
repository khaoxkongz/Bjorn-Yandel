# STGB — ดัชนี

## ข้อมูลโครงการ

- ชื่อเรื่องไทย: **เอาชีวิตรอดในเกมฉบับคนเถื่อน**
- ชื่อเรื่องอังกฤษ: **Surviving Game as a barbarian**
- คำอธิบายเนื้อเรื่องโดยย่อ: อีฮันซู เขาคือชายหนุ่มผู้เล่นเกม [ดันเจียน แอนด์ สโตน] ที่ไม่มีใครเคยเคลียร์ได้มาก่อนเป็นเวลาถึง 9 ปี จนมาถึงบอสตัวสุดท้าย แต่เมื่อเขาเข้าไปในห้องบอส เขากลับได้เข้ามาอยู่ในร่างของ “บยอร์น ยานเดล” คนเถื่อนแห่งเกม [ดันเจียน แอนด์ สโตน] วิธีเดียวที่คุณจะเอาชีวิตในเกมนี้ได้ คือคุณต้องเข้าไปยังเขาวงกตและต่อสู้โดยเอาชีวิตของคุณเป็นเดิมพัน ด้วยกลยุทธ์ตลอด 9 ปีที่ผ่านมาและร่างกายอันกำยำของคนเถื่อน ยังไงซะ ฉันก็จะเอาตัวรอดในเกมนี้ให้ได้!
- ภาษาต้นทางสำหรับงานแปล: ฉบับแฟนแปลภาษาอังกฤษจากต้นฉบับภาษาเกาหลี
- ภาษาปลายทาง: ภาษาไทย

## ลำดับการอ้างอิงก่อนเริ่มแปล

ทุกเซสซันให้ตรวจตามลำดับดังนี้:

1. `00_ดัชนี.md` — ตรวจรุ่น ขอบเขตตอน หลักของฉบับแปล ลำดับอำนาจ และกติกากลาง
2. เปิด `01_พระเอก.md`, `02_พวกพ้องพระเอก.md` หรือ `03_เสียงตัวละครอื่น.md` เฉพาะไฟล์ที่เกี่ยวข้องกับผู้บรรยาย ฉาก และตัวละคร
3. เปิด `04_ศัพท์ระบบ.md`, `05_สถานที่.md` หรือ `06_องค์กร_กลุ่ม_หน่วยงาน.md` ตามประเภทข้อมูลที่ต้องตรวจ
4. `07_ตัวละคร.md` — ตรวจรูปชื่อ ตัวตน และนามแฝงของตัวละคร
5. เปิด `08_สกิล.md` หรือ `09_ไอเทม_อุปกรณ์_มอนสเตอร์.md` เพื่อตรวจชื่อแฟนตาซีที่เกี่ยวข้อง

หนังสือและตำราการแปลขั้นสูงใช้เป็นกรอบวิเคราะห์และช่วยตัดสินใจ แต่เมื่อมีหลายรูปแปลที่ถูกต้อง ให้ยึดรสนิยมการอ่านของผู้ใช้ตามหลักของฉบับแปลและไฟล์เสียงพูดที่เกี่ยวข้อง เว้นแต่รูปนั้นทำให้ข้อเท็จจริง กลไกระบบ ความรู้ของตัวละคร หรือบุคลิกหลักคลาดเคลื่อน

## หลักของฉบับแปล

- เป็นฉบับเรียบเรียงเพื่อการอ่านส่วนตัวของผู้ใช้
- ให้ความสำคัญกับความมีชีวิตชีวา อารมณ์ร่วม เสียงตัวละคร และภาษาไทยร่วมสมัย
- อนุญาตให้ขยาย เรียบเรียง หรือเคลื่อนน้ำหนักจากต้นฉบับเล็กน้อยเพื่อสร้างอารมณ์
- ห้ามเปลี่ยนข้อเท็จจริง กลไกระบบ ลำดับเหตุการณ์ ความรู้ของตัวละคร และบุคลิกหลัก
- ไม่ใช้ความกระชับเป็นเกณฑ์สูงสุด และไม่ตัดคำเพียงเพราะประโยคยาวกว่าต้นฉบับ
- เมื่อวิจารณ์บทแปล ให้แยกระหว่างรสนิยมผู้ใช้ บุคลิกเคลื่อน และสารคลาดเคลื่อนอย่างชัดเจน

ไฟล์ลำดับ 01–03 เก็บเฉพาะข้อมูลที่มีผลโดยตรงต่อการแปล ได้แก่ **POV/narrator, persona, สรรพนาม, คำเรียก, ระดับภาษา, จังหวะพูด/คิด, วิธีแสดงอารมณ์ และความสัมพันธ์ที่เปลี่ยนภาษา**

### พื้นที่รับผิดชอบ

| ไฟล์ | เจ้าของข้อมูล |

| `01_พระเอก.md` | narrator identity อีฮันซู + persona พระเอกทั้งหมด รวมหน้ากากสิงโต |

### ขั้นตอนพิจารณา

1. ระบุ **POV / narrator**
2. ระบุ **speaker** ของแต่ละบทพูด
3. ระบุ **persona/public role** ที่กำลัง active
4. ระบุ **คู่สนทนาและความสัมพันธ์** ที่มีผลต่อภาษา
5. ระบุ Character Card ของคนที่กำลังพูด/เป็นคู่สนทนาสำคัญ

### ลำดับความสำคัญ

เมื่อข้อมูลดูชนกัน ให้เรียงดังนี้:

1. ต้นฉบับฉากปัจจุบัน
2. HARD CORE / CORE ของผู้พูด
3. Persona/public role ที่ active
4. Relationship ที่ active
5. Conditional ที่ถูก trigger
6. พัฒนาการหรือข้อมูลฉากหลัง

ต้นฉบับฉากปัจจุบันมีสิทธิ์ลบล้าง pattern เดิมเสมอ

### หลักการแยกข้อมูล

- รายการหนึ่งควรมี **แหล่งหลักเพียงไฟล์เดียว** เพื่อลดการแก้ศัพท์ซ้ำหลายจุด
- หากเป็นชื่อสถานที่ ให้ไป `05_สถานที่.md` ก่อนเสมอ
- หากเป็นองค์กร กลุ่ม หรือหน่วยงาน ให้ใช้ส่วนที่ตรงประเภทภายใน `06_องค์กร_กลุ่ม_หน่วยงาน.md`
- ตำแหน่งทั่วไป เหตุการณ์ และคำที่ไม่ใช่ชื่อหน่วยหรือกลุ่ม ให้เก็บใน `04_ศัพท์ระบบ.md`
- ถ้าหลักฐานยังไม่พอจะแยกประเภท ให้คงรายการไว้ในหมวดที่กว้างกว่าและใส่สถานะ `รอตรวจ` แทนการเดา

### วิธีอ้างอิงภายในหมวด

1. เริ่มจากตารางโครงสร้างด้านบนเพื่อยืนยันขอบเขตของแต่ละไฟล์
2. เปิดไฟล์ตามประเภทของคำที่ต้องตรวจ
3. หากคำหนึ่งดูเกี่ยวข้องได้มากกว่าหนึ่งหมวด ให้พิจารณา **หน้าที่ของสิ่งนั้นในเรื่อง** มากกว่ารูปคำภาษาอังกฤษเพียงอย่างเดียว
4. ห้ามสร้างรูปแปลใหม่เพียงเพราะหาไม่พบในไฟล์แรก ให้ตรวจไฟล์ที่เกี่ยวข้องก่อน

### กติกาการสร้างคำ

ช่อง **วิธีสร้างคำ** ใช้ประเภท ได้แก่ `เทียบความหมาย`, `คำอธิบาย`, `คำยืม`, `คำกว้าง+คำขยาย`, `แทนทางวัฒนธรรม` และ `ตามบริบท` สามารถใช้หลายวิธีร่วมกันได้ เมื่อเพิ่มศัพท์ใหม่ต้องกรอกช่องนี้

### ขอบเขตของพจนานุกรม

ให้ทำหน้าที่เป็น **พจนานุกรมชื่อภาษาไทย** เท่านั้น โดยควรเก็บชื่ออังกฤษ ชื่อไทย ประเภท และรูปสะกดอื่นจากฉบับแฟนแปล

### วิธีสร้างชื่อศัพท์แฟนตาซี

เมื่อพบชื่อสกิล ไอเทม อุปกรณ์ หรือมอนสเตอร์ ให้บันทึกวิธีสร้างชื่อก่อนเสนอเป็นมาตรฐาน:

| วิธี | ใช้เมื่อ | ข้อควรระวัง |
| --- | --- | --- |
| เทียบความหมาย | ชื่อมีภาพหรือหน้าที่ที่ถ่ายทอดเป็นไทยได้ชัด | รักษาพลัง ระดับภาษา และประเภทของสิ่งนั้น |
| คำยืม/ถอดเสียง | ชื่อเป็นอัตลักษณ์เฉพาะหรือเป็นศัพท์เกมที่ผู้อ่านไทยคุ้นเคย | กำหนดรูปสะกดเดียวและบันทึกรูปอื่น |
| คำยืม+คำกว้าง | ต้องรักษาชื่อเฉพาะและบอกประเภท เช่น ดาบ บริษัท หรือโกเลม | อย่าอธิบายยาวจนกลายเป็นประโยค |
| คำกว้าง+คำขยายหน้าที่ | ไม่มีคำไทยตรงและหน้าที่สำคัญกว่ารูปลักษณะ | อย่าเติมกลไกที่ต้นฉบับไม่บอก |
| ตามบริบท | คำเดียวทำหน้าที่ต่างกันจริง | ห้ามใช้เพื่อแก้ความไม่สม่ำเสมอโดยไม่มีเหตุผล |
| แทนทางวัฒนธรรม | วิธีอื่นสื่อสารไม่ได้และไม่กระทบข้อเท็จจริง | โดยปกติไม่ใช้กับชื่อเฉพาะและการสร้างโลกของ STGB |
