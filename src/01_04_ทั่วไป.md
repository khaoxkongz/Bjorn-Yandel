# ฮยอนบยอล / HS123

## CORE

- ใช้ **ฉัน** เรียกอีฮันซูว่า **พี่**; ภาษาไทยร่วมสมัยแบบคนโลกเดิม
- เหน็บแนม จับผิด และทักนิสัยหลบเลี่ยงของอีฮันซูได้ตรง ๆ
- ให้ความสำคัญกับ **ขอบเขตส่วนตัว/ความยินยอม**; สุภาพได้โดยไม่หมายถึงเปิดรับความสนิท
- กับอีฮันซูยังเป็นกันเอง แม้มีแรงเสียดทาน; เมื่อห่วงใยมักอยู่เป็นเพื่อนหรือไม่ซัก มากกว่าปลอบยาว
- ห้ามทำให้พูดหวานหรือยอมตามง่ายโดยไม่มี source รองรับ

## CONDITIONAL

- **public_role:** เมื่อต้องปิดบังตัวตน/ความสัมพันธ์ เปลี่ยนเป็นสุภาพทางการได้แนบเนียน; รับมุกบยอร์นแบบหน้าตายโดยไม่เล่นตามเกินจำเป็น
- **boundary_violation:** หากถูกล้ำเส้นหรือกระทบจิตใจโดยไม่ขออนุญาต เตือนและกำหนดเส้นตรง ๆ โดยไม่จำเป็นต้องขึ้นเสียง
- **specific_knowledge:** ถ้าถูกถามสิ่งที่รู้ ตอบตรงและไม่โอ้อวด
- **secretary_or_assistant_role:** ในตัวตนภายนอกแบบเลขานุการ/ผู้ช่วย ตอบสั้น ตรง มีมารยาท อธิบายภูมิหลังหรือความสัมพันธ์เท่าที่จำเป็น แล้วถอนตัวเมื่อหน้าที่จบ

## SOURCE CONSTRAINT

- ใน Ep. 448 บยอร์น **เชื่อว่า “ฮาริน ซูเอวี” คือฮยอนบยอล** จากเบาะแสที่มี
- ไฟล์นี้ **ห้ามใช้เป็นหลักฐานยืนยันว่าทั้งสองคือคนเดียวกัน** ต่อบุคคลอื่น ก่อนต้นฉบับเปิดเผยชัดเจน
- หากฉากใช้ชื่อ **ฮาริน ซูเอวี** ให้รักษา public-role voice และระดับข้อมูลเท่าที่ตัวละครในฉากรู้

# มาร์ควิสเทอร์เซริออน

## CORE

- สุขุม เป็นทางการ คุมจังหวะดี; ใช้คำถามทดสอบความคิด/ปฏิกิริยา
- แม้ตกใจหรือถูกข่ม มักเสียอาการสั้นแล้วกลับมาคุมภาษา
- พูดเรื่องผลประโยชน์ การเมือง และกำลังอย่างตรงโดยไม่ต้องขึ้นเสียง
- ภาษาสุภาพ/สง่างามอาจเป็นเครื่องมือ ไม่ใช่หลักฐานว่าเป็นมิตรหรือจริงใจ
- เด่นด้าน **ประคองเรื่องเล่าและคุมความเสียหายทางการเมือง**
- กับเอลตราเย็นชาและกดดันกว่าบุคคลภายนอก

## CONDITIONAL

- **political_damage_control:** เมื่อเกิดความเสียหายสาธารณะ รีบสร้างคำอธิบาย รักษาหน้า โยนรายละเอียดความผิดไปยังผู้เกี่ยวข้องได้ แล้วเข้าสู่ค่าชดเชย/ทางออก
- **ceremonial_politeness:** รักษาถ้อยคำพิธีการแม้ความจริงใจต่ำ; ต้องคงช่องว่างระหว่างคำพูดกับผลประโยชน์

# เอลตรา เทอร์เซริออน

## CORE

- สุภาพและให้ความเคารพบยอร์น; ความตึงเครียดออกผ่านหลบสายตา เว้นจังหวะ และเลือกคำ
- ขอโทษตามมารยาทได้แม้ตนเป็นฝ่ายถูกทำร้าย เพราะต้องรักษาความสัมพันธ์ทางการเมือง
- ห้ามทำให้สนิทหรือผ่อนคลายกับบยอร์นเร็วเกินพัฒนาการจริง

## CONDITIONAL

- **command_duty:** ต่อหน้าผู้ใต้บังคับบัญชาใช้คำสั่งสั้น สุภาพ คุมสีหน้า; ความขัดแย้ง/รู้สึกผิดเก็บไว้ภายใน ไม่ระบายต่อหน้ากองทหาร

# ดยุกเคอัลลูนัส

## CORE

- ขุนนางอาวุโส มีพิธีรีตอง ใช้ประโยคเต็ม และให้ความสำคัญกับมารยาท/ฐานันดร/ภาพลักษณ์
- หยั่งเชิงทางการเมืองด้วยถ้อยคำสุภาพอ้อมก่อนถามตรงขึ้น
- ปรับประโยคให้สั้นลงได้เมื่อเห็นว่าบยอร์นไม่รับจังหวะขุนนาง
- คำว่า **เพื่อน** อาจเป็นผลประโยชน์และการจัดขั้ว ไม่ใช่มิตรภาพจริงใจโดยอัตโนมัติ

## CONDITIONAL

- **public_mediation:** เมื่อห้ามความขัดแย้งต่อหน้าคนมาก ใช้ภาษารักษาหน้าและพากลับสู่กรอบพิธีการ; หากรู้ว่าฝ่ายที่ช่วยผิดจริง เปลี่ยนจุดยืนเร็วได้
- **personal_guarantee:** ใช้ชื่อ/ฐานะตนรับรองเพื่อจบความเสียหายแทนการเถียงยาว
- **ambiguous_friendship:** หากถูกเรียก “เพื่อน” ต่อสาธารณะ ตอบรับอบอุ่นได้โดยไม่ยืนยัน/ปฏิเสธตรง ๆ

# บารอนเนสลิริเวีย

## CORE

- สุภาพ สำรวม แบบขุนนาง; ใช้เหตุผลและประโยคเต็ม
- เข้าใจการเมืองและผลประโยชน์; ความสุภาพไม่ใช่ความไร้เดียงสา
- เจรจาตรงขึ้นได้เมื่อจำเป็นโดยไม่ทำให้เป็นคำขู่
- แม้ถูกเหยียดสามารถรักษารอยยิ้ม/เสียงไว้; ความโกรธและอัดอั้นจึงออกผ่านเนื้อหาและน้ำหนักมากกว่าระเบิดอารมณ์
- เมื่อเห็นวิธีที่ให้ผลจริง สามารถเปลี่ยนจากอดทนระวังตัวเป็นมุ่งมั่นขึ้น
- กับบยอร์นเสียจังหวะต่อพฤติกรรมคนเถื่อนได้ แต่กลับมาคิดเชิงเหตุผลเร็ว

## CONDITIONAL

- **racial_pressure:** เมื่อถูกเหยียด รักษามารยาทภายนอกแต่ไม่ลดความโกรธ; การอดทนไม่เท่ากับไม่รู้สึก
- **political_negotiation:** ต่อรองการสนับสนุน/ทรัพยากรได้ตรงขึ้นและยอมรับแรงจูงใจด้านผลประโยชน์อย่างเปิดเผย
- **endurance_to_action:** เมื่อ source แสดงว่าการอดทนไม่พอ น้ำเสียงมุ่งมั่นและพร้อมผลักการเปลี่ยนแปลงมากขึ้น โดยยังคงบุคลิกผู้นำตระกูล
- **meeting_moderator:** เมื่อเป็นผู้ดำเนินการประชุม จัดวาระ เปิดให้คัดค้าน/ซักถาม เรียกลงคะแนน และประกาศผลด้วยภาษาสุภาพเป็นขั้นตอน; แม้ช่วยผลักข้อเสนอของตนก็ยังยอมรับกติกาและผลโหวต รวมถึงแสดงความประหลาดใจได้เมื่อผลเกินคาด

# บารอนเฮสไครา

## CORE

- ขุนนางกึ่งมนุษย์ พูดสุภาพ เป็นทางการ และใช้เหตุผลเชิงความรับผิดชอบต่อครอบครัว/คนรุ่นหลัง
- สามารถเป็นตัวแทนพูดแทนกลุ่มเมื่อบรรยากาศเปลี่ยน โดยคำสุภาพอาจแฝงการปฏิเสธที่ชัดและหนักแน่น
- ยึดกฎและความเสี่ยงทางการเมืองสูง แต่ไม่ใช่คนขี้ขลาด; เมื่อให้คำแนะนำ น้ำเสียงสามารถฟังเหมือนผู้อาวุโสที่หวังดีมากกว่าคู่แข่ง
- หากถูกวิจารณ์การตัดสินใจโดยตรง น้ำเสียงเย็นลงได้ทันที แต่ยังไม่เปลี่ยนเป็นการด่าหรือหาเรื่อง

## CONDITIONAL

- **policy_debate:** ถามตรงเรื่องกฎไม่เป็นลายลักษณ์อักษร ผลกระทบต่อฝ่ายอื่น และอนาคตของตระกูล; เมื่อได้รับคำตอบตรงสามารถยอมรับว่าอย่างน้อยตนเข้าใจว่าคู่สนทนาเป็นคนแบบไหน แม้ยังไม่เห็นด้วย

## DON'T

- ห้ามทำให้ความระมัดระวัง = ความขลาดหรือไร้วิสัยทัศน์ทุกฉาก

# บารอนบรูเวลลิน

## CORE

- ขุนนางกึ่งมนุษย์รุ่นหนุ่มจากเผ่าหมาป่าขาว; พูดสุภาพและสนับสนุนการเปลี่ยนแปลงมากกว่าสมาชิกเมลเบธสายอนุรักษนิยม
- มองโอกาสทางการเมือง/เขาวงกตเชิงยุทธศาสตร์ และพร้อมตั้งคำถามกับแนวทางเดิมเมื่อเห็นว่ากลุ่มกำลังเสียโอกาส
- การสนับสนุนข้อถกเถียงไม่เท่ากับเห็นด้วยทั้งหมด; สามารถเสนอว่าเรื่องหนึ่ง **ควรพิจารณา** โดยยังสงวนจุดยืนสุดท้าย

## DON'T

- ห้ามทำให้ความต้องการเปลี่ยนแปลง = ความบุ่มบ่ามหรือสนับสนุนบยอร์นทุกเรื่องโดยอัตโนมัติ

# รักนา ริทาเนียล เปปร็อก / ไวเคาน์เตสเปปร็อก

## CORE

- กับบยอร์นใช้ **ข้า/เจ้า** ได้แบบคนรู้จักเก่า และเรียกชื่อ/นามสกุลกันตรง ๆ โดยไม่ต้องใช้ภาษาขุนนางเต็มรูป
- ลิ้นคม ถามตรง และสวนกลับได้; หลังผ่านเวลา น้ำเสียงนิ่ง สุขุม และมั่นใจขึ้นกว่าสมัยเป็นบรรณารักษ์
- เมื่อต้องเล่าเรื่องส่วนตัวที่เป็นบาดแผล สามารถลังเล/เว้นจังหวะ แต่ยังเรียบเรียงข้อเท็จจริงเป็นลำดับและยอมเปิดเรื่องที่เคยปิดบัง
- เรื่องการยอมรับวิญญาณร้ายเป็น **อุดมการณ์ของเธอเอง** ไม่ใช่สิ่งที่ทำเพื่อบยอร์นเพียงอย่างเดียว
- ความรู้สึกต่อมาร์ควิสเทอร์เซริออนยังซับซ้อน; สามารถเรียกว่าเป็นคนแปลกหน้า แต่ปกป้องเหตุผลหรือมุมมองที่ตนเชื่อเกี่ยวกับเขาได้

## CONDITIONAL

- **friendship_exposure:** เมื่อพูดว่าบยอร์นเป็นเพื่อนหรือยอมรับว่าทำบางอย่างเพื่อเขา อาจหลบสายตา/เสียจังหวะเล็กน้อย; ห้ามขยายเป็นโรแมนติกเกิน source
- **private_selfish_reason:** ในฉากส่วนตัวสามารถยอมรับเหตุผลเห็นแก่ตัวเล็ก ๆ แบบหน้าตาย เช่นใช้อำนาจเพื่อให้ได้กลับมาพบกันในสถานที่เดิม
- **ideological_stand:** หากบยอร์นเสนอให้ถอนตัวจากเกมอำนาจ เธอสามารถยืนยันอุดมการณ์ของตนอย่างหนักแน่นโดยไม่เปลี่ยนเป็นการทะเลาะทางอารมณ์

## DON'T

- ห้ามทำให้ความนิ่งปัจจุบันย้อนกลับเป็นความเปราะบางแบบอดีตทุกฉาก
- ห้ามตีความความซับซ้อนเรื่องมาร์ควิสเป็นการยอมรับสายสัมพันธ์ครอบครัวแล้ว

# ชาบิน เอมูร์

## CORE

- ภาษาไทยร่วมสมัยแบบมนุษย์ในเมือง; กับเพื่อนเก่าอย่างบยอร์นไม่ต้องใช้ภาษาราชการ
- เมื่อเข้าสู่โหมดงาน พูดเป็นระบบ ชัด และแบ่งงานตามความถนัดโดยไม่ใช้อำนาจแข็งแบบทหาร
- มีทักษะบริหารคน: ใช้ความรับผิดชอบ บทบาทในอนาคต และการทำงานร่วมกันเป็นแรงจูงใจ
- ให้ความสำคัญกับความรู้สึกว่า **ตนเป็นคนที่อีกฝ่ายต้องการจริง ๆ** มากกว่าการรับความช่วยเหลือเปล่า
- เมื่อเจอข้อมูลเหนือคาด สามารถเสียจังหวะ/ถามย้ำ แต่กลับเข้าสู่โหมดจัดระบบได้เร็ว

## CONDITIONAL

- **tribal_administration:** ในฐานะผู้ดูแลงานบริหาร แบ่งงานเป็นสถิติ การเงิน พัฒนาเมือง และวางโครงให้ขยายเป็นฝ่ายเมื่อมีคนเพิ่ม
- **overwork_motivation:** เมื่อลูกทีมบ่นงานหนัก ใช้เหตุผลเชิงปฏิบัติและประสบการณ์ร่วม เช่นเคยทำโอที ได้ค่าจ้างเพิ่ม และพักมาแล้ว; ไม่ใช่หัวหน้ากดขี่หรือผู้ปลุกใจโอ่อ่า

## DON'T

- ห้ามทำให้ความเก่งบริหารกลายเป็นบุคลิกแข็งแบบผู้บังคับบัญชาทหาร
- ห้ามตีความการรับงานว่าเธอยอมรับการสงเคราะห์

# ฮิคูร็อด มูราด

## CORE

- พูดเสียงดัง เป็นกันเอง ใช้ **ข้า/เจ้า** กับบยอร์น และหัวเราะ **ฮ่าฮ่า** ได้ตามธรรมชาติ
- ชอบข่าวซุบซิบ/เรื่องความสัมพันธ์จนถามส่วนตัวเกินได้ แต่เมื่ออ่านว่าบรรยากาศอันตรายจะหัวเราะแห้งและถอยทันที
- เรื่องธุรกิจทำให้กระตือรือร้นแบบช่าง/พ่อค้า; ความไว้ใจเพื่อนสูงจนมองว่าสัญญาทางการอาจไม่จำเป็น
- เมื่อพูดถึงความฝันหรือสถานเลี้ยงเด็กกำพร้า สามารถเปลี่ยนเป็นจริงจังและจริงใจทันที โดยไม่ต้องสละสลวย

## CONDITIONAL

- **rare_material_excitement:** เจออุปกรณ์/วัสดุหายากแล้วตื่นเต้นจนพูดติดขัดหรือแทบไม่ได้ยินคำเตือน; ความตื่นเต้นไม่เท่ากับความโลภ
- **risky_business:** งานที่โยงราชวงศ์ทำให้คัดค้าน/เตือนก่อน แต่หากความอยากรู้อยากเห็นและผลประโยชน์ชนะความกลัว สามารถยอมรับด้วยตรรกะตรง ๆ ว่า **ถ้าไม่ถูกจับได้ก็ไม่มีปัญหา**

## DON'T

- ห้ามทำให้ความช่างเมาท์ = อ่านสถานการณ์ไม่เป็น
- ห้ามทำให้ความตื่นเต้นของช่างลบความเป็นห่วงเพื่อนหรือการประเมินความเสี่ยง

# ร็อตมิลเลอร์

## CORE

- สุขุม เรียบ รับผิดชอบสูง; ใช้ประโยคตรงและมักคอยห้ามฮิคูร็อดไม่ให้ก้าวล้ำคนอื่น
- เก็บปัญหาตนเองและไม่ต้องการใช้ฐานะ/เส้นสายของเพื่อนแก้เรื่องส่วนตัว
- หากไม่ต้องการให้อีกฝ่ายพูดต่อ สามารถลดเสียงให้เย็นและเด็ดขาดโดยไม่ขึ้นเสียง
- ความสุขุมไม่ใช่ไร้อารมณ์; เมื่อเรื่องแตะขีดจำกัด ความรับผิดชอบ หรือความล้มเหลวของตน สามารถแสดงความโกรธชัด

## CONDITIONAL

- **refuse_favor_for_self:** เมื่อคนอื่นพยายามขอความช่วยเหลือหรือใช้เส้นสายแทนตน สามารถตัดบทแข็งกว่าปกติเพื่อรักษาขอบเขตและความรับผิดชอบของตน

---

# กุดนุลฟ์ โอลกา / หัวหน้าเผ่าคนก่อน

## CORE

- คนเถื่อนเต็มตัว ใช้ **ข้า/เจ้า** พูดตรง หนักแน่น และไม่ใช้ภาษาโบราณประดิษฐ์
- ในบริบทสำคัญเรียกบยอร์นว่า **บยอร์น บุตรแห่งยานเดล**
- ในการต่อสู้ไม่พูดพร่ำหรือยั่วยุเพื่อสร้างภาพ; ความหมายมาจากการลงมือและคำประกาศสั้น
- ต้องแยก **ยอมรับผู้สืบทอด** ออกจาก **ยอมแพ้ในการดวล**: ยอมรับว่าบยอร์นเหมาะกับเผ่าได้โดยยังสู้จนสุดทาง
- หลังเสียตำแหน่ง เสียงผ่อนคลายและตรงขึ้น; ปัดเรื่องการเมืองว่าไม่ใช่หน้าที่และนิยามตนเป็นนักรบคนเถื่อนธรรมดา
- สิ่งที่ไม่รู้ให้ตอบว่า **ไม่รู้**; ห้ามอธิบายกลไกเหนือธรรมชาติเกินประสบการณ์

## CONDITIONAL

- **old_tribal_history:** เมื่อเล่าอดีตเผ่า สามารถพูดยาวและรำลึกยุคทองด้วยเสียงหัวเราะแบบคนแก่คิดถึงวันเก่า
- **king_memory:** เรื่องกษัตริย์หรือความทรงจำหนักทำให้จังหวะหายใจ/เว้นคำเผยความกลัวได้ โดยยังไม่แต่งข้อเท็จจริง
- **retired_barbarian:** หลังเกษียณสามารถตัดบทเพราะหิว พูดเรื่องความเป็นความตายตรง ๆ และไม่อยากรับภาระบริหาร; ห้ามทำเป็นผู้อาวุโสเคร่งขรึมทุกฉาก

---

# มาลิด เคฟรอน

## CORE

- รองหัวหน้าแคลนฟันเลื่อย; พูดสุภาพ เป็นทางการ และกล้าหยั่งเชิงกับบยอร์น
- ใช้ชื่อผู้สนับสนุนหรืออำนาจเป็นแรงกดดันแบบอ้อมมากกว่าขู่ตรง
- หากคำพูดเปิดช่องให้อีกฝ่ายเอาผิด จะรีบขอโทษชัด ไม่แก้ตัว และยอมรับเฉพาะจุดที่เสียเปรียบ
- มีไหวพริบทางการเมือง: หลีกเลี่ยงถ้อยคำที่เป็นหลักฐาน และห่อผลประโยชน์แคลนด้วยเหตุผลเรื่องความปลอดภัย ความเข้าขากัน หรือหน้าที่ต่อผู้อ่อนแอกว่า
- ความสุภาพไม่ใช่ความอ่อนน้อมจริงใจ; ปฏิเสธความร่วมมือได้หนักแน่นโดยยังรักษามารยาท

## CONDITIONAL

- **after_physical_pressure:** หลังถูกบยอร์นข่มด้วยกำลัง ยังพยายามคุมถ้อยคำและลดความเสียหายต่อแคลน มากกว่าตอบโต้ด้วยศักดิ์ศรี
- **protect_raid_share:** หากถอนตัวเพื่อไม่แบ่งผลประโยชน์ สามารถพูดเป็นเหตุผลที่ดูรับผิดชอบและยกย่องอีกฝ่าย; ต้องรักษาช่องว่างระหว่าง **ถ้อยคำสุภาพ** กับ **เจตนาปกป้องส่วนแบ่งแคลน**
- **raid_loot_dispute:** เมื่อโต้แย้งสิทธิ์เหนือบอส/ของดรอป เริ่มจากกรอบกติกานักสำรวจและสิทธิ์จากการเรด ก่อนเรียกค่าชดเชยผ่านกลไกทางการ เช่นราคาประเมินของกิลด์; หากถูกกดหนักสามารถลดข้อเรียกร้องเป็นทางประนีประนอมได้
- **standoff_under_witnesses:** เมื่อบยอร์นบีบให้เลือกสู้หรือถอย และมีพยานจำนวนมากเข้ามา ความโกรธ/ศักดิ์ศรีไม่ทำให้เลือกเปิดศึกที่เสียเปรียบ; สามารถสั่งถอนตัวแล้วทิ้งคำเตือนว่าจะไปสะสางต่อในเมือง
- **anger_register_drop:** เมื่อโกรธจัดจากการเสียของดรอป สามารถหลุดลดคำให้เกียรติชั่วคราว แต่เมื่อกลับเข้าสู่การต่อรองจะคืนสู่ภาษาสุภาพและเป็นทางการ

## DON'T

- ห้ามตีความความสุภาพว่าโปร่งใสหรือจริงใจ
- ห้ามเพิ่มคำขู่ตรงหาก source ใช้แรงกดดันอ้อม

---

# ลูอิส ซิยูร์

## CORE

- ใช้ **ผม/ครับ** และพูดสุภาพ
- เมื่อบยอร์นสั่ง/เรียกกะทันหัน สามารถเสียจังหวะ ถามย้ำ หรือติดขัด
- ความประหม่าไม่ใช่ความไร้ความสามารถ; รับคำอธิบายเชิงปฏิบัติและทำตามคำสั่งได้
- หากถูกโยนหน้าที่ดูแลคนจำนวนมากโดยไม่ทันตั้งตัว ปฏิกิริยาแรกอาจลนลาน ก่อนยอมรับและเข้าสู่หน้าที่

---

## QC

- ใช้เฉพาะคน active
- Conditional ต้องมี trigger
- ภาษาสุภาพของขุนนาง/นักการเมืองไม่เท่ากับความจริงใจ
- อย่าใช้ public-role voice ปนกับ private voice โดยไม่มีเหตุผล
- อย่าเปลี่ยนการควบคุมอารมณ์เป็นความไร้อารมณ์
- อย่าใช้ inference ของบยอร์นเป็นข้อเท็จจริงที่ตัวละครอื่นรู้
