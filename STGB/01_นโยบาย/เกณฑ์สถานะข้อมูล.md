# STGB — เกณฑ์สถานะข้อมูล

## สถานะที่อนุญาต

ใช้สถานะหลักเพียงห้าชนิด:

- `บังคับ`
- `มาตรฐาน`
- `ชั่วคราว`
- `รอตรวจ`
- `เลิกใช้`

ห้ามใส่ประเภท บทบาท หรือปัญหาการตรวจไว้รวมในช่องสถานะ

## บังคับ

ผู้ใช้กำหนดให้ใช้รูปนี้โดยตรง

กฎการใช้งาน:

- ห้ามเปลี่ยนโดยอัตโนมัติ
- มีอำนาจเหนือข้อมูลมาตรฐาน
- การแก้ไขต้องได้รับคำตัดสินใหม่จากผู้ใช้
- ควรบันทึกเหตุผลหรือวันที่กำหนดเมื่อทราบ

## มาตรฐาน

ข้อมูลได้รับการตรวจแล้วและใช้เป็นค่าปริยายของโครงการ

กฎการใช้งาน:

- ใช้โดยอัตโนมัติเมื่อบริบทตรงกัน
- เปลี่ยนได้เมื่อมีหลักฐานใหม่หรือคำตัดสินใหม่
- การเปลี่ยนรูปมาตรฐานต้องบันทึกใน `CHANGELOG.md`

## ชั่วคราว

ข้อมูลสามารถใช้ทำงานได้ แต่หลักฐานยังไม่เพียงพอให้เป็นมาตรฐาน

กฎการใช้งาน:

- ใช้ได้จนกว่าจะมีข้อมูลใหม่
- ต้องไม่ถูกอธิบายว่าเป็นข้อสรุปสุดท้าย
- ควรมีหมายเหตุว่าขาดข้อมูลใด
- เมื่อมีหลักฐานเพียงพอให้เลื่อนเป็น `มาตรฐาน`
- หากพบปัญหาที่กระทบการใช้งานให้เปลี่ยนเป็น `รอตรวจ`

## รอตรวจ

ข้อมูลมีข้อสงสัยหรือความขัดแย้งที่ต้องตรวจสอบก่อนใช้อย่างมั่นใจ

ตัวอย่าง:

- รูปอังกฤษไม่แน่นอน
- รูปแปลไทยมีหลายทางเลือก
- ประเภทของสิ่งนั้นยังไม่ชัด
- ข้อมูลจากสองแหล่งขัดกัน
- ไม่แน่ใจว่าเป็นชื่อเฉพาะหรือคำทั่วไป
- กลไกหรือความสัมพันธ์ยังสรุปไม่ได้

กฎการใช้งาน:

- ต้องระบุประเด็นที่รอตรวจ
- ควรเชื่อมไปยังไฟล์ใน `90_รอตรวจ`
- ห้ามเลื่อนเป็นมาตรฐานโดยไม่มีหลักฐานหรือคำตัดสิน

## เลิกใช้

ข้อมูลเคยถูกใช้ แต่ไม่ควรใช้ในงานใหม่

กฎการใช้งาน:

- เก็บไว้เพื่อค้นหารูปเก่าหรือป้องกันการใช้ซ้ำ
- ต้องระบุรูปใหม่ที่ใช้แทนเมื่อมี
- ห้ามลบประวัติทันที
- การเลิกใช้ต้องบันทึกใน `CHANGELOG.md`

## ข้อมูลที่ไม่ใช่สถานะ

ข้อมูลต่อไปนี้ต้องแยกออกจากช่องสถานะ:

| ข้อมูลเดิม | ตำแหน่งใหม่ |
| --- | --- |
| ชื่อผู้ใช้ | `ประเภท` |
| ชื่อปลอม | `ประเภท` |
| ฉายา | `ประเภท` |
| ต้นหน | `บทบาท` หรือ `หมายเหตุ` |
| สาวใช้ | `บทบาท` หรือ `หมายเหตุ` |
| มาตรฐานทางทหาร | `สถานะ: มาตรฐาน` และ `ขอบเขต: ทางทหาร` |
| มาตรฐานตามบริบท | `สถานะ: มาตรฐาน` และ `ขอบเขต: ตามบริบท` |
| รอตรวจต้นฉบับ | `สถานะ: รอตรวจ` และระบุปัญหาใน `หมายเหตุ` |
| ชั่วคราว/รอตรวจชื่อ | ใช้ `สถานะ: รอตรวจ` |
| ยืนยันแล้ว | เปลี่ยนเป็น `มาตรฐาน` |

## ช่องเสริมที่แนะนำ

ข้อมูลแต่ละรายการอาจใช้ช่องต่อไปนี้:

- `ประเภท`
- `สถานะ`
- `ขอบเขตการใช้`
- `บทบาท`
- `ปรากฏครั้งแรก`
- `ตรวจถึงตอน`
- `หมายเหตุ`
- `ปัญหาที่ต้องตรวจ`
- `หลักฐาน`

## การเปลี่ยนสถานะ

เส้นทางปกติ:

`ข้อเสนอใหม่ → รอตรวจ → ชั่วคราว → มาตรฐาน`

เส้นทางอื่นที่เป็นไปได้:

- `รอตรวจ → มาตรฐาน`
- `ชั่วคราว → รอตรวจ`
- `มาตรฐาน → เลิกใช้`
- `มาตรฐาน → บังคับ` เมื่อผู้ใช้กำหนด
- `บังคับ → เลิกใช้` เมื่อผู้ใช้เปลี่ยนคำตัดสิน

ทุกครั้งที่เปลี่ยนสถานะ `มาตรฐาน`, `บังคับ` หรือ `เลิกใช้` ให้บันทึกใน `CHANGELOG.md`
