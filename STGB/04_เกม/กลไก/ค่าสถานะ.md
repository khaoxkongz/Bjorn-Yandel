# STGB — ค่าสถานะ ความสามารถ และคำศัพท์ระบบ

## จุดประสงค์

เอกสารนี้เก็บชื่อและข้อเท็จจริงเกี่ยวกับ:

* ค่าสถานะ
* ค่าสถานะพิเศษ
* ความสามารถ
* รายการที่ยังแยกไม่ชัดระหว่างค่าสถานะกับความสามารถ
* คำศัพท์ที่เกี่ยวข้องกับระบบ
* คำศัพท์ที่ยังไม่ทราบประเภทแน่นอน

ข้อมูลที่สามารถเก็บเมื่อมีหลักฐาน ได้แก่

* รหัสรายการ
* ชื่ออังกฤษ
* ชื่อไทย
* ประเภท
* สถานะชื่อ
* ค่าตัวเลข
* หน่วย
* ช่วงค่า
* สูตรคำนวณ
* สิ่งที่ค่าดังกล่าวส่งผล
* วิธีเพิ่มหรือลดค่า
* ความสัมพันธ์กับสกิล ไอเทม หรือเอฟเฟกต์
* ข้อจำกัดและข้อยกเว้น
* ช่วงตอนและหลักฐาน

## สถานะข้อมูลปัจจุบัน

ไฟล์ต้นทางยืนยันเพียง:

* ชื่ออังกฤษ
* ชื่อไทย
* ประเภท
* สถานะชื่อ

ไฟล์ต้นทางยังไม่ระบุ:

* ค่าตัวเลข
* หน่วย
* ช่วงค่าต่ำสุดหรือสูงสุด
* สูตรคำนวณ
* วิธีเพิ่มหรือลดค่า
* ผลของแต่ละค่า
* ผู้ที่มีค่าสถานะ
* ความสัมพันธ์ระหว่างค่า
* การแสดงผลในหน้าต่างระบบ
* การรีเซ็ตหรือการฟื้นคืนค่า

ดังนั้น ห้ามเติมกลไกจากชื่อของรายการเพียงอย่างเดียว

# ประเภทข้อมูล

| ประเภท | ความหมายในการจัดเก็บ |
| ------------------- | ------------------------------------------------------------------------ |
| ค่าสถานะ | แหล่งเดิมจัดรายการเป็นค่าสถานะ แต่ยังไม่จำเป็นต้องมีค่าตัวเลขที่ทราบแล้ว |
| ค่าสถานะพิเศษ | แหล่งเดิมแยกจากค่าสถานะทั่วไป |
| ความสามารถ | แหล่งเดิมจัดเป็นความสามารถ ไม่ใช่สกิลโดยอัตโนมัติ |
| ค่าสถานะ/ความสามารถ | ยังไม่ยืนยันว่าควรอยู่ในประเภทใด |
| คำศัพท์ | ทราบว่าเป็นศัพท์เฉพาะ แต่ยังไม่ทราบประเภทหรือหน้าที่ |
| คำศัพท์ระบบ | คำที่ใช้เรียกแนวคิดหรือข้อมูลของระบบ |

## ข้อห้ามเกี่ยวกับประเภท

* ห้ามเปลี่ยน `ความสามารถ` เป็น `สกิล` จากชื่อเพียงอย่างเดียว
* ห้ามเปลี่ยน `ค่าสถานะพิเศษ` เป็นค่าสถานะทั่วไป
* ห้ามเลือกประเภทเดียวให้รายการ `ค่าสถานะ/ความสามารถ` จนกว่าจะมีหลักฐาน
* ห้ามสรุปว่าคำศัพท์หนึ่งเป็นค่าสถานะเพียงเพราะปรากฏในหน้าต่างระบบ
* ห้ามถือว่าค่าสถานะทุกชนิดต้องเป็นตัวเลข
* ห้ามตีความคำที่คล้ายอารมณ์ว่าเป็นอารมณ์ปกติของตัวละครโดยอัตโนมัติ

## สิ่งที่ยืนยันได้

* ทั้งเจ็ดรายการถูกจัดเป็น `ค่าสถานะ`
* ชื่อไทยปัจจุบันมีสถานะ `ชั่วคราว`
* ยังไม่มีข้อมูลตัวเลขหรือกลไกในไฟล์ต้นทาง

## สิ่งที่ยังไม่ทราบ

* เป็นค่าตัวเลขหรือระดับเชิงคุณภาพ
* มีช่วงค่าต่ำสุดหรือสูงสุดหรือไม่
* ค่าเพิ่มหรือลดอย่างไร
* ใช้กับบุคคล สิ่งมีชีวิต ไอเทม หรือระบบประเภทใด
* ค่าหนึ่งส่งผลต่ออีกค่าหนึ่งหรือไม่
* ค่าถูกแสดงให้ตัวละครเห็นหรือไม่
* เป็นสถานะถาวรหรือเปลี่ยนแปลงตามเหตุการณ์
* สามารถฟื้นคืน รีเซ็ต หรือลบล้างได้หรือไม่

## ข้อห้าม

* ห้ามใช้ความหมายทางจิตวิทยาทั่วไปแทนกลไกของระบบ
* ห้ามเขียนว่าค่าใดสูงหรือต่ำโดยไม่มีตัวเลขหรือคำบรรยายรองรับ
* ห้ามสรุปว่า `Control` ลด `Impulse`
* ห้ามสรุปว่า `Deficiency` เพิ่ม `Obsession`
* ห้ามสรุปว่า `Distrust` หรือ `Ownership` เป็นความรู้สึกของตัวละครโดยตรง
* ห้ามสร้างสูตรความสัมพันธ์ระหว่างค่าทั้งเจ็ด
* ห้ามใช้ชื่อไทยเป็นหลักฐานว่าค่าทำงานอย่างไร

# ความสามารถ

## manifestation power

* ID: `ability.manifestation_power`
* อังกฤษ: `manifestation power`
* ไทย: `พลังเนรมิต`
* ประเภท: ความสามารถ
* สถานะ: ชั่วคราว

### สิ่งที่ยืนยันได้

* แหล่งเดิมจัดเป็น `ความสามารถ`
* ชื่ออังกฤษในไฟล์เดิมใช้ตัวพิมพ์เล็ก
* ชื่อไทยปัจจุบันคือ `พลังเนรมิต`

### สิ่งที่ยังไม่ทราบ

* เป็นความสามารถติดตัวหรือเปิดใช้
* มีค่าตัวเลขหรือไม่
* เกี่ยวข้องกับสกิลใด
* ใช้ทรัพยากรหรือไม่
* มีขอบเขตหรือข้อจำกัดอย่างไร
* ส่งผลต่อการสร้าง การเรียก หรือการทำให้สิ่งหนึ่งปรากฏหรือไม่
* สามารถเพิ่มหรือลดได้หรือไม่

### ข้อห้าม

* ห้ามสรุปว่าหมายถึงการสร้างวัตถุ
* ห้ามสรุปว่าหมายถึงการอัญเชิญ
* ห้ามสรุปว่าหมายถึงพลังเวท
* ห้ามเปลี่ยนประเภทเป็นสกิล
* ห้ามเปลี่ยนตัวพิมพ์อังกฤษโดยไม่ตรวจต้นฉบับ

# ค่าสถานะพิเศษ

## Recovery Power

* ID: `stat.recovery_power`
* อังกฤษ: `Recovery Power`
* ไทย: `พลังฟื้นฟู`
* ประเภท: ค่าสถานะพิเศษ
* สถานะ: ชั่วคราว

### สิ่งที่ยืนยันได้

* แหล่งเดิมจัดเป็น `ค่าสถานะพิเศษ`
* ไม่ได้จัดเป็นสกิล
* ชื่อไทยปัจจุบันคือ `พลังฟื้นฟู`

### สิ่งที่ยังไม่ทราบ

* ฟื้นฟูสิ่งใด
* เป็นค่าปริมาณหรืออัตรา
* ใช้กับพลังชีวิต พลังเวท ร่างกาย หรือสิ่งอื่น
* ทำงานตลอดเวลาหรือเฉพาะเงื่อนไข
* มีหน่วยหรือเปอร์เซ็นต์หรือไม่
* เกี่ยวข้องกับสกิล `[สัมผัสเยียวยา]` หรือ `[เซลล์ดึกดำบรรพ์]` หรือไม่
* ได้รับผลจากไอเทมหรือแกนหรือไม่

### ข้อห้าม

* ห้ามแปลขยายเป็น `อัตราการฟื้นฟู`
* ห้ามสรุปว่าใช้รักษาบาดแผล
* ห้ามสรุปว่าเพิ่มการฟื้นพลังชีวิต
* ห้ามเชื่อมกับ `skill.healing_touch`
* ห้ามเชื่อมกับ `skill.primordial_cell`
* ห้ามกำหนดหน่วยหรือสูตรคำนวณ

# รายการที่ประเภทคลุมเครือ

## Physical Resistance

* ID: `stat.physical_resistance`
* อังกฤษ: `Physical Resistance`
* ไทย: `ค่าต้านทานทางกายภาพ`
* ประเภท: ค่าสถานะ/ความสามารถ
* สถานะ: ชั่วคราว

### สิ่งที่ยืนยันได้

* ชื่อไทยมีคำว่า `ค่า`
* แหล่งเดิมยังจัดประเภทไว้สองแบบ คือ `ค่าสถานะ/ความสามารถ`
* ยังไม่ได้ยืนยันให้เป็นประเภทใดประเภทหนึ่ง

### สิ่งที่ยังไม่ทราบ

* เป็นค่าตัวเลขหรือความสามารถ
* ลดความเสียหายทางกายภาพหรือไม่
* เกี่ยวข้องกับการต้านสถานะทางกายภาพหรือไม่
* คำนวณก่อนหรือหลังพลังป้องกันหรือไม่
* มีหน่วยหรือเปอร์เซ็นต์หรือไม่
* ใช้กับตัวละคร มอนสเตอร์ ไอเทม หรือทั้งหมด
* สามารถเพิ่มจากอุปกรณ์หรือสกิลหรือไม่

### ข้อห้าม

* ห้ามสรุปว่าเท่ากับพลังป้องกัน
* ห้ามสรุปว่าเป็นเปอร์เซ็นต์ลดความเสียหาย
* ห้ามสรุปว่าต้านการโจมตีทุกชนิด
* ห้ามเปลี่ยนประเภทเป็นค่าสถานะถาวร
* ห้ามเปลี่ยนประเภทเป็นความสามารถติดตัว
* ห้ามรวมกับเกราะหรือความทนทานของอุปกรณ์

### สถานะการตรวจ

`รอตรวจประเภท`

# คำศัพท์รอตรวจ

## Iblus

* ID: `term.iblus`
* อังกฤษ: `Iblus`
* ไทย: `อิบลุส`
* ประเภท: คำศัพท์
* สถานะ: รอตรวจต้นฉบับ

### สิ่งที่ยืนยันได้

* มีชื่อ `Iblus`
* รูปไทยปัจจุบันคือ `อิบลุส`
* แหล่งเดิมจัดเป็น `คำศัพท์`
* ต้องตรวจต้นฉบับก่อนยืนยัน

### สิ่งที่ยังไม่ทราบ

* เป็นชื่อเฉพาะหรือคำทั่วไป
* เป็นค่าสถานะ ความสามารถ วัตถุ สิ่งมีชีวิต หรือแนวคิด
* ต้องใช้ตัวพิมพ์ใหญ่หรือไม่
* รูปถอดเสียงถูกต้องหรือไม่
* เกี่ยวข้องกับระบบใด
* ควรย้ายไปไฟล์ประเภทใดหลังตรวจสอบ

### ข้อห้าม

* ห้ามกำหนดความหมายเอง
* ห้ามเปลี่ยนประเภท
* ห้ามสร้างคำแปลเชิงความหมาย
* ห้ามเชื่อมกับสกิล ไอเทม มอนสเตอร์ หรือองค์กรโดยไม่มีหลักฐาน
* ห้ามเปลี่ยนสถานะเป็นมาตรฐาน

### หลักฐานที่ต้องหา

* ประโยคเต็มที่คำนี้ปรากฏ
* รูปต้นฉบับภาษาหลัก
* หน้าต่างระบบหรือคำอธิบายที่เกี่ยวข้อง
* ตัวพิมพ์ใหญ่และการสะกดในแต่ละแหล่ง
* บริบทว่าคำนี้ใช้เรียกสิ่งใด

* ไทย: `ระดับไอเทม`
* ประเภท: คำศัพท์ระบบ
* สถานะ: มาตรฐานตามบริบท

### กฎการใช้

ใช้ `ระดับไอเทม` เมื่อกล่าวถึงค่าหรือแนวคิดของระบบที่บ่งบอกระดับของไอเทม

สถานะ `มาตรฐานตามบริบท` หมายความว่า:

* ใช้เป็นรูปหลักเมื่อบริบทกล่าวถึงระบบ
* ไม่จำเป็นต้องทำให้เป็นชื่อเฉพาะ
* ไม่จำเป็นต้องใส่วงเล็บเหลี่ยม
* สามารถปรับโครงสร้างประโยคให้เป็นธรรมชาติได้
* ต้องรักษาความหมายว่าเป็นระดับของไอเทม

### สิ่งที่ยังไม่ทราบ

* รูปแบบค่าที่ใช้
* ช่วงระดับ
* วิธีเพิ่มระดับ
* ความสัมพันธ์กับคุณภาพหรืออันดับไอเทม
* ความสัมพันธ์กับหมายเลขไอเทม
* ระดับส่งผลต่อค่าสถานะอย่างไร
* ตัวละครมองเห็นค่านี้ผ่านระบบหรือการประเมิน

### ข้อห้าม

* ห้ามสรุปว่าเลขหมายไอเทมคือระดับไอเทม
* ห้ามสรุปว่าไอเทมหมายเลขสูงมีระดับสูงกว่า
* ห้ามใช้แทนคำว่าอันดับ คุณภาพ หรือความหายากโดยอัตโนมัติ
* ห้ามเติมค่าระดับที่ต้นฉบับไม่ได้ระบุ

* เก็บค่าตามต้นฉบับ

* ระบุช่วงตอน
* ห้ามถือว่าค่าจากคนหนึ่งใช้กับทุกคน
* ห้ามถือว่าค่าจากตอนหนึ่งคงเดิมในตอนหลัง

# การเชื่อมกับสกิลและเอฟเฟกต์

เมื่อมีหลักฐานว่าค่าสถานะสัมพันธ์กับสกิล ให้บันทึกใน:

`สกิลและเอฟเฟกต์.md`

พร้อมอ้างอิงกลับมายัง ID ในไฟล์นี้

รูปแบบ:

```md id="3sn2ti"

- เงื่อนไข:

- ตอน:
- หลักฐาน:
- สถานะ:
```

ประเภทความสัมพันธ์อาจเป็น:

* เพิ่ม
* ลด

# การเชื่อมกับไอเทม

เมื่อมีหลักฐานว่าไอเทมส่งผลต่อค่าสถานะ:

1. ใช้ ID จาก `../ไอเทม.md`
2. ใช้ ID ค่าสถานะจากไฟล์นี้
3. เก็บค่าตัวเลขและหน่วยตามต้นฉบับ
4. ระบุว่าเป็นผลขณะสวมใส่ ผลถาวร หรือผลเปิดใช้
5. ระบุข้อจำกัด
6. ห้ามเก็บเจ้าของไอเทมปัจจุบันเป็นกฎถาวร

รูปแบบ:

```md id="2u1v9h"
## ผลของไอเทมต่อค่าสถานะ

- ไอเทม:
- ค่าสถานะ:
- ผล:
- ค่า:
- หน่วย:
- เงื่อนไข:
- ระยะเวลา:
- ตอน:
- หลักฐาน:
- สถานะ:
```

## การสร้าง ID

ใช้คำนำหน้าตามประเภท:

| ประเภท | คำนำหน้า |
| ------------- | ---------- |
| ค่าสถานะ | `stat.` |
| ความสามารถ | `ability.` |
| คำศัพท์ทั่วไป | `term.` |
| คำศัพท์ระบบ | `system.` |

ตัวอย่าง:

```text id="ulw5jx"
stat.obsession
stat.recovery_power
ability.manifestation_power
term.iblus
system.item_level
```

## ก่อนเพิ่มรายการ

ตรวจว่า:

1. รายการนี้เป็นค่าสถานะ สกิล เอฟเฟกต์ หรือคำศัพท์
2. มีรายการชื่อเดียวกันอยู่แล้วหรือไม่
3. ชื่ออังกฤษต่างกันเป็นรายการเดียวกันหรือไม่
4. คำไทยเพิ่มความหมายที่ต้นฉบับไม่ได้ระบุหรือไม่
5. มีค่าตัวเลขหรือหน่วยจริงหรือไม่
6. มีหลักฐานว่าค่านี้ส่งผลต่ออะไรหรือไม่
7. ประเภทได้รับการยืนยันหรือยัง
8. ต้องส่งไป `../../90_รอตรวจ/ข้อเสนอใหม่.md` ก่อนหรือไม่
9. มีข้อมูลขัดแย้งที่ต้องส่งไป `../../90_รอตรวจ/ข้อมูลขัดแย้ง.md` หรือไม่
