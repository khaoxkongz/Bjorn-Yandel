# STGB — สกิลและความสามารถ

## จุดประสงค์

เอกสารนี้เป็นพจนานุกรมชื่อภาษาไทยของสกิลและความสามารถในโครงการ

ให้เก็บ:

* รหัสสกิล
* ชื่ออังกฤษหลัก
* ชื่อไทยหลัก
* รูปอังกฤษอื่น
* ประเภท
* สถานะชื่อ
* หมายเหตุสั้นเพื่อแยกรายการที่อาจสับสนกัน

ไม่ให้เก็บ:

* กลไกสกิลโดยละเอียด
* ค่าสถานะ
* ระยะ
* คูลดาวน์
* เปอร์เซ็นต์
* เงื่อนไขการเปิดใช้
* ลำดับเหตุการณ์การใช้สกิล
* ผู้ใช้สกิล
* เป้าหมายของสกิลในแต่ละฉาก
* ข้อสรุปทางยุทธวิธี
* รายละเอียดเนื้อเรื่อง

ข้อมูลกลไกที่ยืนยันแล้วให้เก็บใน:

`กลไก/สกิลและเอฟเฟกต์.md`

## กฎการจัดเก็บ

1. หนึ่งสกิลมีหนึ่งรายการ
2. รูปอังกฤษหลายแบบให้รวมไว้ในรายการเดียว
3. รักษาเครื่องหมายวงเล็บเหลี่ยมของชื่อสกิลตามมาตรฐานเดิม
4. ห้ามเปลี่ยนคำแปลชั่วคราวเป็นมาตรฐานโดยไม่มีหลักฐาน
5. ห้ามรวมสกิลสองรายการเพียงเพราะมีความหมายคล้ายกัน
6. ห้ามแยกสกิลหนึ่งเป็นหลายรายการเพียงเพราะฉบับแฟนแปลใช้ชื่ออังกฤษต่างกัน
7. ประเภท `สกิล/เอฟเฟกต์` หมายความว่ายังต้องตรวจว่ารายการนั้นเป็นชื่อสกิลหรือชื่อผลของสกิล
8. หากความสัมพันธ์ระหว่างชื่อยังไม่ชัด ให้เก็บทั้งสองรายการและทำเครื่องหมาย `รอตรวจ`
9. ห้ามเพิ่มเจ้าของสกิลจากความทรงจำหรือการคาดเดา
10. การเปลี่ยนชื่อที่มีผลต่อบทแปลเดิมต้องบันทึกใน `CHANGELOG.md`

## สถานะที่ใช้

| สถานะ         | ความหมาย                                                        |
| ------------- | --------------------------------------------------------------- |

| ชั่วคราว      | ใช้ได้ในปัจจุบัน แต่ยังแก้ไขได้เมื่อพบหลักฐานเพิ่ม              |
| รอตรวจ        | ยังมีข้อสงสัยเกี่ยวกับชื่อ ประเภท หรือความสัมพันธ์กับรายการอื่น |
| รอตรวจต้นฉบับ | ต้องตรวจข้อความต้นฉบับก่อนยืนยัน                                |
| ตามบริบท      | รูปแปลอาจเปลี่ยนตามหน้าที่จริงของคำในประโยค                     |

# รายการรอตรวจ

## Call of the Underworld

* ID: `skill.call_of_the_underworld`
* ชื่อไทยปัจจุบัน: `[เสียงเรียกแห่งปรโลก]`
* ปัญหา: ต้องตรวจต้นฉบับ
* ระหว่างรอตรวจ: ใช้รูปปัจจุบันโดยรักษาสถานะ `รอตรวจต้นฉบับ`

## Evolved Armor / Evolved Shell / Evolved Hide

รายการที่เกี่ยวข้อง:

* `skill.evolved_armor`
* `skill.evolved_hide`

ปัญหาที่ยังไม่ยืนยัน:

* `Evolved Armor` และ `Evolved Shell` เป็นชื่อเดียวกันหรือไม่
* `Evolved Hide` เป็นชื่อสกิลเดียวกันหรือเป็นเอฟเฟกต์แยก
* `[เกราะวิวัฒน์]` และ `[หนังวิวัฒน์]` ต้องใช้แยกตามต้นฉบับหรือไม่

ระหว่างรอตรวจ:

* ห้ามรวมรายการ
* ห้ามเปลี่ยนชื่อไทยรายการใดรายการหนึ่งให้เหมือนกัน
* รักษารูปที่มีอยู่ในบทแปลเดิม
* ส่งหลักฐานใหม่ไป `../90_รอตรวจ/ข้อมูลขัดแย้ง.md`

- หน้าที่หรือภาพที่ชื่อสื่อ:
- ปรากฏครั้งแรก:
- รูปอังกฤษอื่น:

## วิธีสร้างชื่อที่ใช้ได้

| วิธี | ใช้เมื่อ | ข้อควรระวัง |
| --------------------------- | -------------------------------------------------- | -------------------------------------------- |
| เทียบความหมาย | ชื่อมีภาพหรือหน้าที่ที่ถ่ายทอดเป็นไทยได้ชัด | รักษาพลังและระดับภาษาของชื่อ |
| คำยืมหรือถอดเสียง | ชื่อเป็นอัตลักษณ์เฉพาะหรือศัพท์เกมที่ควรรักษาเสียง | กำหนดรูปสะกดหลักและบันทึกรูปอื่น |
| คำยืมร่วมกับคำกว้าง | ต้องรักษาชื่อเฉพาะและบอกประเภท | อย่าอธิบายยาวจนกลายเป็นประโยค |
| คำกว้างร่วมกับคำขยายหน้าที่ | ไม่มีคำไทยตรงและหน้าที่สำคัญกว่ารูปลักษณ์ | ห้ามเติมกลไกที่ต้นฉบับไม่บอก |
| ตามบริบท | คำเดียวทำหน้าที่ต่างกันจริง | ห้ามใช้เพื่อแก้ความไม่สม่ำเสมอโดยไม่มีเหตุผล |
| แทนทางวัฒนธรรม | วิธีอื่นสื่อสารไม่ได้และไม่กระทบข้อเท็จจริง | โดยปกติไม่ใช้กับชื่อเฉพาะของ STGB |

## ก่อนเพิ่มรายการ

ตรวจว่า:

1. มีชื่อเดียวกันอยู่แล้วหรือไม่
2. เป็นสกิล เอฟเฟกต์ ค่าสถานะ หรือคำระบบ
3. รูปอังกฤษต่างกันเป็นสกิลเดียวกันหรือไม่
4. เครื่องหมายวงเล็บเหลี่ยมตรงกับมาตรฐานของโครงการหรือไม่
5. คำแปลเผยกลไกที่ต้นฉบับไม่ได้บอกหรือไม่
6. มีความสัมพันธ์กับรายการรอตรวจหรือไม่
7. ต้องเพิ่มข้อมูลกลไกแยกใน `กลไก/สกิลและเอฟเฟกต์.md` หรือไม่
8. ต้องบันทึกข้อเสนอใน `../90_รอตรวจ/ข้อเสนอใหม่.md` ก่อนหรือไม่

## การสร้าง ID

* ใช้อักษรอังกฤษตัวเล็ก
* ใช้ `_` คั่นคำ
* เริ่มด้วย `skill.`
* ตัดเครื่องหมายวรรคตอนออก
* เมื่อกำหนดแล้วไม่ควรเปลี่ยนตามคำแปลไทย

ตัวอย่าง:

```text id="mhm2z5"
skill.eye_of_the_storm
skill.dragon_speech
skill.call_of_the_underworld
```
