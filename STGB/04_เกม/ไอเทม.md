# STGB — ไอเทมและอุปกรณ์

## จุดประสงค์

เอกสารนี้เป็นพจนานุกรมชื่อภาษาไทยของไอเทม อุปกรณ์ และวัสดุในโครงการ

ให้เก็บ:

* รหัสไอเทม
* ชื่ออังกฤษหลัก
* ชื่อไทยหลัก
* รูปอังกฤษอื่น
* ประเภท
* หมายเลขไอเทมเมื่อมี
* สถานะชื่อ
* หมายเหตุสั้นเพื่อแยกรายการที่อาจสับสนกัน

ไม่ให้เก็บ:

* เจ้าของปัจจุบัน
* สถานที่เก็บ
* สถานะว่าถูกขาย หล่น จำนำ หรือทำลาย
* ราคา
* ค่าสถานะ
* ความทนทาน
* เงื่อนไขการใช้งาน
* กลไกโดยละเอียด
* ลำดับเหตุการณ์ที่ใช้ไอเทม
* ข้อสรุปทางยุทธวิธี
* รายละเอียดเนื้อเรื่อง

ข้อมูลกลไกที่ยืนยันแล้วให้เก็บในไฟล์กลไกที่เกี่ยวข้อง

## กฎการจัดเก็บ

1. หนึ่งไอเทมมีหนึ่งรายการ
2. รูปอังกฤษหลายแบบให้รวมในรายการเดียว
3. หมายเลขไอเทมเป็นส่วนหนึ่งของชื่อเมื่อแหล่งข้อมูลระบุ
4. ห้ามตัดหมายเลขออกจากชื่อมาตรฐาน
5. ห้ามเพิ่มหมายเลขให้รายการที่ต้นทางไม่ได้ระบุ
6. รักษาเครื่องหมายวงเล็บเหลี่ยมของชื่อไทยตามข้อมูลเดิม
7. ห้ามเปลี่ยนสถานะ `ชั่วคราว` เป็น `มาตรฐาน` โดยไม่มีหลักฐาน
8. ประเภทต้องแยกจากสถานะชื่อ
9. ห้ามรวมวัสดุการสลักเข้ากับไอเทมทั่วไปโดยไม่เก็บประเภทเดิม
10. รายการที่มีข้อมูลขัดแย้งต้องส่งไป `../90_รอตรวจ/ข้อมูลขัดแย้ง.md`
11. การแก้ชื่อที่กระทบบทแปลเดิมต้องบันทึกใน `../CHANGELOG.md`

ใช้รูปแบบ:

```text
หมายเลข N — [ชื่อไอเทม]
```

ห้าม:

* ตัดคำว่า `หมายเลข`
* ลบหมายเลขออกจากชื่อ
* เปลี่ยนเป็น `ลำดับที่`
* ย้ายหมายเลขไปไว้ท้ายชื่อ
* เติมเครื่องหมายหรือคำอธิบายที่ต้นทางไม่ได้ระบุ

# รายการตามบริบท

รายการต่อไปนี้เป็นชื่ออุปกรณ์ทั่วไปและมีสถานะ `ตามบริบท`:

| ID | อังกฤษ | ไทย |
| ------------------------ | ----------------- | ------------- |
| `item.steel_breastplate` | Steel Breastplate | เกราะอกเหล็ก |
| `item.steel_greaves` | Steel Greaves | สนับแข้งเหล็ก |
| `item.war_boots` | War Boots | รองเท้าศึก |

สถานะ `ตามบริบท` หมายความว่า:

* ใช้คำไทยตามหน้าที่ของอุปกรณ์ในประโยค
* ไม่จำเป็นต้องจัดรูปเป็นชื่อเฉพาะทุกครั้ง
* ห้ามเปลี่ยนชนิดอุปกรณ์
* ห้ามเติมคุณสมบัติที่ต้นฉบับไม่ระบุ
* หากพบว่าเป็นชื่อเฉพาะจริง ให้เสนอเปลี่ยนสถานะพร้อมหลักฐาน

## ก่อนเพิ่มรายการ

ตรวจว่า:

1. เป็นไอเทม สกิล วัสดุ หรือคำระบบ
2. มีรายการชื่อเดียวกันอยู่แล้วหรือไม่
3. หมายเลขเป็นส่วนหนึ่งของชื่อหรือไม่
4. รูปอังกฤษหลายแบบเป็นสิ่งเดียวกันหรือไม่
5. เครื่องหมายวงเล็บเหลี่ยมตรงกับมาตรฐานเดิมหรือไม่
6. คำแปลเติมคุณสมบัติที่ต้นฉบับไม่ได้บอกหรือไม่
7. มีสถานะการตั้งชื่อปลอมหรือไม่
8. มีข้อมูลขัดแย้งที่ต้องส่งไป `../90_รอตรวจ` หรือไม่

## การสร้าง ID

* ใช้อักษรอังกฤษตัวเล็ก
* ใช้ `_` คั่นคำ
* เริ่มด้วย `item.`
* สำหรับไอเทมหมายเลขให้ขึ้นต้นชื่อส่วนหลังด้วย `no_`
* เมื่อกำหนด ID แล้วไม่ควรเปลี่ยนตามคำแปลไทย

ตัวอย่าง:

```text
item.arc_steel_sword
item.book_of_souls
item.no_87_krauls_demon_crusher
item.no_1911_pavelers_broken_pocket_watch
```
