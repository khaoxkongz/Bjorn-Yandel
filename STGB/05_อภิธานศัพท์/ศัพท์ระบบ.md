# STGB — ศัพท์ระบบ

## จุดประสงค์

เอกสารนี้เป็นอภิธานศัพท์หลักสำหรับคำที่เกี่ยวข้องกับ:

* ระบบเกม
* เขาวงกต
* สกิลและสถานะ
* การต่อสู้
* แกนและไอเทม
* เวทมนตร์
* โลกแห่งจิตวิญญาณ
* ระบบผู้เล่น
* ระบบผู้ดูแล
* แนวคิดเฉพาะของโลกเรื่อง

เอกสารนี้กำหนด:

* รูปอังกฤษหลัก
* รูปอังกฤษอื่น
* รูปไทยหลัก
* วิธีสร้างคำ
* สถานะของคำ
* หมายเหตุการใช้งานสั้น

รายละเอียดกลไกให้เก็บใน:

`../04_เกม/กลไก/`

## ขอบเขตอำนาจ

ไฟล์นี้เป็นแหล่งหลักสำหรับ **รูปคำและสถานะการแปล**

ไฟล์นี้ไม่ใช่แหล่งหลักสำหรับ:

* สูตรคำนวณ
* ตัวเลข
* ระยะเวลา
* ระยะทาง
* ระยะพักของสกิลเฉพาะ
* กลไกการทำงาน
* ประวัติเนื้อเรื่อง
* ผู้ครอบครองสกิลหรือไอเทม
* ความสัมพันธ์ระหว่างตัวละคร

หากชื่อในไฟล์นี้ขัดกับชื่อเฉพาะในทะเบียนสกิล ไอเทม หรือมอนสเตอร์ ให้ตรวจลำดับอำนาจข้อมูลก่อนแก้ไข

# วิธีสร้างคำ

| วิธี | ความหมาย |
| ----------------------- | -------------------------------------- |
| เทียบความหมาย | ใช้คำไทยที่ถ่ายทอดความหมายหลัก |
| เทียบความหมายตามหน้าที่ | เลือกคำไทยจากหน้าที่ของสิ่งนั้นในบริบท |
| เทียบความหมายตามบริบท | เลือกความหมายให้เหมาะกับบริบทที่ปรากฏ |
| คำอธิบาย | ใช้คำอธิบายแทนคำตรงตัว |
| คำอธิบายตามหน้าที่ | อธิบายสิ่งที่คำหรือสิ่งนั้นทำ |
| คำยืม/ถอดเสียง | รักษาเสียงของคำต้นฉบับ |
| คำยืม/คงรูป | รักษารูปอักษรต้นฉบับ |
| คำยืม+เทียบความหมาย | รักษาบางส่วนของชื่อและแปลส่วนที่เหลือ |
| คำยืม+คำอธิบาย | รักษาคำยืมร่วมกับคำอธิบาย |
| คำยืม/ตามบริบท | ใช้คำยืมโดยปรับโครงสร้างตามประโยค |
| คำกว้าง+คำขยาย | ใช้คำบอกประเภทและเพิ่มคำขยาย |
| ตามบริบท | รูปคำอาจเปลี่ยนตามหน้าที่จริงในประโยค |

## กฎ

* ทุกศัพท์ใหม่ต้องระบุวิธีสร้างคำ
* สามารถใช้หลายวิธีร่วมกันได้
* หากรูปคำยังไม่ลงตัว ต้องอธิบายปัญหาในหมายเหตุ
* ห้ามเปลี่ยนวิธีสร้างคำเดิมโดยไม่มีเหตุผล
* วิธีสร้างคำไม่ได้ยืนยันกลไกของศัพท์นั้น

# สถานะคำ

| สถานะ | ความหมาย |
| --------------- | --------------------------------------------------- |
| บังคับ | ต้องใช้รูปนี้ เว้นแต่มีการแก้มาตรฐานอย่างเป็นทางการ |
| มาตรฐาน | เป็นรูปหลักของโครงการ |
| มาตรฐานตามระบบ | เป็นรูปหลักเมื่อกล่าวถึงระบบโดยตรง |
| มาตรฐานตามบริบท | เป็นรูปหลัก แต่สามารถปรับโครงสร้างให้เหมาะกับประโยค |
| ชั่วคราว | ใช้ได้ในปัจจุบัน แต่ยังแก้ไขได้ |
| ตามบริบท | ต้องเลือกหรือปรับรูปตามหน้าที่ในประโยค |
| รอตรวจ | ยังมีข้อสงสัยเกี่ยวกับชื่อหรือความหมาย |
| รอตรวจต้นฉบับ | ต้องตรวจข้อความต้นฉบับก่อนยืนยัน |

## ก่อนเพิ่มรายการ

ตรวจว่า:

1. เป็นศัพท์ทั่วไปหรือชื่อเฉพาะ
2. เป็นสกิล ไอเทม มอนสเตอร์ สถานที่ หรือองค์กรหรือไม่
3. มีรูปเดียวกันอยู่แล้วหรือไม่
4. รูปอังกฤษต่างกันเป็นแนวคิดเดียวกันหรือไม่
5. คำไทยเพิ่มกลไกที่ต้นฉบับไม่ได้ระบุหรือไม่
6. ควรใช้คำแปลหรือคำถอดเสียง
7. สถานะควรเป็นบังคับ มาตรฐาน ชั่วคราว หรือตามบริบท
8. ต้องส่งไป `../90_รอตรวจ/ข้อเสนอใหม่.md` ก่อนหรือไม่
9. มีข้อมูลขัดแย้งที่ต้องส่งไป `../90_รอตรวจ/ข้อมูลขัดแย้ง.md` หรือไม่
