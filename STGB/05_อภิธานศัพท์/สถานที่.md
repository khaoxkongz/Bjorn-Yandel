# STGB — สถานที่

## จุดประสงค์

เอกสารนี้เป็นทะเบียนชื่อสถานที่และคำเรียกพื้นที่ในโครงการ

ให้เก็บ:

* รหัสสถานที่
* ชื่ออังกฤษหลัก
* ชื่อไทยหลัก
* รูปอังกฤษอื่น
* ประเภทสถานที่
* วิธีสร้างคำ
* สถานะชื่อ
* หมายเหตุสั้นเพื่อแยกรายการที่อาจสับสนกัน

ไม่ให้เก็บ:

* เหตุการณ์ที่เกิดขึ้นในสถานที่
* ผู้ที่อยู่ในสถานที่ปัจจุบัน
* เส้นทางการเดินทาง
* ระยะทาง
* เวลาเดินทาง
* การครอบครองพื้นที่ตามช่วงเรื่อง
* สถานะว่าถูกทำลายหรือยึดครอง
* รายละเอียดภูมิประเทศที่ชื่อไม่ได้ยืนยัน
* ประวัติศาสตร์ของสถานที่

ข้อมูลบริบทช่วงเรื่องให้เก็บใน:

`../06_ขอบเขตเรื่อง/บริบทช่วงปัจจุบัน.md`

## กฎการจัดเก็บ

1. หนึ่งสถานที่มีหนึ่งรายการ
2. รูปอังกฤษหลายแบบให้รวมไว้ในรายการเดียว
3. ห้ามรวมสถานที่เพียงเพราะชื่อไทยคล้ายกัน
4. ห้ามแยกสถานที่เพียงเพราะฉบับแฟนแปลใช้รูปอังกฤษต่างกัน
5. ห้ามเติมประเภทสถานที่จากชื่อเพียงอย่างเดียวเมื่อข้อมูลยังไม่ชัด
6. คำเรียกพื้นที่ทั่วไปสามารถมีสถานะ `ตามบริบท`
7. ชื่อเฉพาะต้องรักษารูปสะกดไทยหลัก
8. รายการที่อาจเป็นองค์กรหรือแนวคิดอื่นให้เก็บในส่วน `รอตรวจหมวด`
9. ห้ามย้ายรายการออกจากไฟล์นี้โดยไม่บันทึกใน `CHANGELOG.md`
10. การแก้ชื่อมาตรฐานต้องตรวจผลกระทบต่อบทแปลเดิม

## สถานะที่ใช้

| สถานะ            | ความหมาย                                            |
| ---------------- | --------------------------------------------------- |
| มาตรฐาน          | ใช้เป็นรูปหลักของโครงการ                            |
| ชั่วคราว         | ใช้ได้ในปัจจุบัน แต่ยังแก้ไขได้                     |
| ตามบริบท         | ปรับรูปตามหน้าที่ในประโยคได้                        |
| รอตรวจรูปต้นฉบับ | ต้องตรวจชื่อหรือรูปสะกดจากต้นฉบับ                   |
| รอตรวจหมวด       | ยังไม่แน่ใจว่าเป็นสถานที่ องค์กร หรือชื่อประเภทอื่น |

* หากยืนยันว่าเป็นคนละสถานที่ ให้สร้าง ID ใหม่และบันทึกหลักฐาน
* หากแก้รูปอังกฤษหลัก ต้องเก็บรูปเดิมไว้เป็นรูปอื่น

# ชื่อที่ต้องระวัง

## Royal Sanctuary และ sanctuary

| อังกฤษ | ไทย |
| --------------- | -------------------------- |
| Royal Sanctuary | เขตศักดิ์สิทธิ์แห่งราชวงศ์ |
| sanctuary | เขตศักดิ์สิทธิ์ |

ห้าม:

* ใช้สองรูปนี้แทนกันโดยอัตโนมัติ
* ตัดคำว่า `แห่งราชวงศ์` เมื่อเป็นชื่อ `Royal Sanctuary`
* เติมคำว่า `แห่งราชวงศ์` เมื่อข้อความใช้เพียง `sanctuary`

## Alminus และ Alminas

รายการ `Alminus Central Exchange / central market of Alminas` มีรูปชื่อพื้นที่ต่างกันระหว่าง:

* `Alminus`
* `Alminas`

ระหว่างรอตรวจ:

* ใช้ชื่อไทย `อัลไมนัส`
* รักษารูปอังกฤษทั้งสอง
* ห้ามแยกเป็นคนละเมืองหรือคนละสถานที่
* บันทึกหลักฐานใหม่ใน `../90_รอตรวจ/ชื่อรอตรวจ.md`

## Pantheon และ Pantelion

รายการซากปรักมีรูป:

* `Pantheon Ruins`
* `Pantelion Ruins`

ระหว่างรอตรวจ:

* ใช้ `ซากปรักแพนธีออน`
* ห้ามตัดรูปใดรูปหนึ่ง
* ห้ามสร้างสถานที่ใหม่
* ต้องตรวจต้นฉบับก่อนปรับมาตรฐาน

## Karnon

รูปอังกฤษ:

* `Karnon, the Imperial City`
* `Imperial City`

รูปไทย:

`นครหลวงคาร์นอน`

ข้อควรระวัง:

* `Imperial City` อาจเป็นคำเรียกตามบริบท
* ห้ามลบชื่อ `คาร์นอน`
* ห้ามแปลทุกกรณีของ `Imperial City` เป็น `นครหลวงคาร์นอน` โดยไม่ตรวจว่าหมายถึงสถานที่เดียวกัน
* สถานะยังเป็น `ชั่วคราว/รอตรวจรูปต้นฉบับ`

# รายการรอตรวจประเภท

## Tovira sect / Tovera Church

ไฟล์ต้นทางจัดรายการนี้ไว้ในหมวดสถานที่:

| อังกฤษ | ไทย |
| --------------------------- | -------------- |
| Tovira sect / Tovera Church | ศาสนจักรโทวิรา |

อย่างไรก็ตาม รูปอังกฤษและไทยอาจหมายถึง:

* องค์กรศาสนา
* ศาสนสถาน
* ทั้งองค์กรและสถานที่ตามบริบท

ดังนั้น:

* ไม่เพิ่มในทะเบียนสถานที่หลักจนกว่าจะยืนยันประเภท
* เก็บรูปแปลไว้ใน `องค์กรและกลุ่ม.md`
* ห้ามสร้างสถานที่ชื่อ `ศาสนจักรโทวิรา` แยกโดยไม่มีหลักฐาน
* บันทึกปัญหาประเภทใน `../90_รอตรวจ/ข้อมูลขัดแย้ง.md`

## Karcia Romne

แหล่งเดิมจัด `Karcia Romne` ไว้ในหมวดสถานที่ แต่ไม่ได้ระบุประเภท

ระหว่างรอตรวจ:

* ใช้ `[คาร์เซีย รอมเน]`
* รักษาวงเล็บเหลี่ยม
* ห้ามกำหนดว่าเป็นเมือง อาคาร หรือพื้นที่
* ห้ามย้ายออกจากทะเบียนจนกว่าจะพบหลักฐาน

## Commelby

แหล่งเดิมไม่ได้ระบุประเภทของ `Commelby`

ระหว่างรอตรวจ:

* ใช้ `คอมเมลบี`
* ห้ามกำหนดว่าเป็นเมืองหรือเขต
* ให้เพิ่มประเภทเมื่อข้อความต้นฉบับยืนยัน

# วิธีเพิ่มสถานที่ใหม่

ใช้รูปแบบ:

```md id="ub307s"
| ID | อังกฤษหลัก | ไทยหลัก | รูปอังกฤษอื่น | ประเภท | วิธีสร้างคำ | สถานะ | หมายเหตุ |
```

ข้อเสนอใหม่ต้องมี:

* ชื่อต้นฉบับ
* ชื่อไทยเสนอ
* ประเภทสถานที่
* วิธีสร้างคำ
* รูปอังกฤษอื่น
* รูปไทยอื่น
* จุดที่ปรากฏครั้งแรก
* บริบทที่ยืนยันว่าเป็นสถานที่
* หลักฐาน
* สถานะ

## การสร้าง ID

* ใช้อักษรอังกฤษตัวเล็ก
* ใช้ `_` คั่นคำ
* เริ่มด้วย `location.`
* ตัดเครื่องหมายวรรคตอนออก
* ใช้ชื่อเฉพาะเป็นหลัก
* หากเป็นคำเรียกทั่วไป ให้ใช้คำอังกฤษเต็มเท่าที่จำเป็น
* เมื่อกำหนด ID แล้วไม่ควรเปลี่ยนตามคำแปลไทย

ตัวอย่าง:

```text id="217m84"
location.noark
location.dimensional_plaza
location.dark_continent
location.karnon_imperial_city
```

## ก่อนเพิ่มรายการ

ตรวจว่า:

1. เป็นสถานที่ องค์กร ไอเทม หรือชื่อบุคคล
2. มีรายการชื่อเดียวกันอยู่แล้วหรือไม่
3. รูปอังกฤษต่างกันเป็นสถานที่เดียวกันหรือไม่
4. ชื่อไทยเพิ่มประเภทที่ต้นฉบับไม่ได้ระบุหรือไม่
5. เป็นชื่อเฉพาะหรือคำเรียกตามหน้าที่
6. ต้องใช้วงเล็บเหลี่ยมหรือไม่
7. มีสถานะมาตรฐานหรือบังคับจากไฟล์เดิมหรือไม่
8. ต้องส่งไป `../90_รอตรวจ/ชื่อรอตรวจ.md` ก่อนหรือไม่
