# STGB — ตำแหน่ง ยศ และบทบาท

## จุดประสงค์

เอกสารนี้เป็นทะเบียนคำเรียกบุคคลตาม:

* ตำแหน่งทางการเมือง
* ตำแหน่งการปกครอง
* ยศและตำแหน่งทางทหาร
* ตำแหน่งทางศาสนา
* ตำแหน่งในองค์กร
* ระดับนักสำรวจ
* บทบาทในทีม
* รูปแบบการต่อสู้
* หน้าที่ชั่วคราวตามภารกิจ

ให้เก็บ:

* รหัส
* ชื่ออังกฤษหลัก
* ชื่อไทยหลัก
* รูปอังกฤษอื่น
* ประเภท
* วิธีสร้างคำ
* สถานะ
* หมายเหตุการใช้สั้น

ไม่ให้เก็บ:

* ชื่อบุคคลที่ดำรงตำแหน่ง
* ประวัติผู้ดำรงตำแหน่ง
* สังกัดปัจจุบันของตัวละคร
* ลำดับบัญชาการตามช่วงเรื่อง
* สมาชิกของหน่วย
* เหตุการณ์แต่งตั้งหรือปลด
* กลไกของคลาสหรือบทบาท
* โปรไฟล์เสียงของผู้ดำรงตำแหน่ง

# กฎการจัดเก็บ

1. หนึ่งตำแหน่งหรือบทบาทมีหนึ่งรายการ
2. รูปอังกฤษหลายแบบให้รวมไว้ในรายการเดียวเมื่อแหล่งเดิมระบุว่าใช้แทนกัน
3. ตำแหน่งต้องแยกจากชื่อองค์กร
4. ยศต้องแยกจากชื่อหน่วยทหาร
5. ชื่อบุคคลที่มีตำแหน่งนำหน้าให้เก็บบุคคลในทะเบียนตัวละคร
6. บทบาทในการต่อสู้ไม่ได้ยืนยันว่าเป็นคลาสของระบบ
7. คำเรียกตามหน้าที่สามารถมีสถานะ `ตามบริบท`
8. ห้ามเปลี่ยนตำแหน่งชั่วคราวเป็นชื่อเฉพาะ
9. ห้ามเพิ่มระดับอำนาจจากคำไทยโดยไม่มีหลักฐาน
10. รูปที่มีสถานะ `มาตรฐานทางทหาร` ต้องรักษาความหมายทางโครงสร้าง
11. การเปลี่ยนชื่อมาตรฐานต้องบันทึกใน `CHANGELOG.md`

## กฎการใช้ Lord

ใช้ `เจ้าเมือง` เมื่อ:

* กล่าวถึงตำแหน่ง
* บรรยายหน้าที่
* กล่าวถึงบุคคลโดยไม่ใช่คำเรียกตรง

ใช้ `ท่านเจ้าเมือง` เมื่อ:

* ตัวละครเรียกผู้ดำรงตำแหน่งโดยตรง
* บริบทมีความสุภาพหรือยอมรับอำนาจ
* รูปประโยคต้องการคำยกย่อง

ห้าม:

* ใช้ `ลอร์ด` โดยอัตโนมัติ
* แปลเป็นฐานันดรขุนนางเมื่อบริบทหมายถึงผู้ปกครองเมือง
* ใช้ `เจ้าเมือง` เป็นชื่อองค์กร
* สร้างตัวละครใหม่จากตำแหน่งเพียงอย่างเดียว

## ระดับความเฉพาะของคำบัญชาการ

เรียงจากคำที่ระบุหน่วยชัดไปหาคำกว้าง:

1. `หัวหน้าหมู่`
2. `หัวหน้าหมวด`
3. `ผู้บัญชาการหน่วย`
4. `ผู้บัญชาการกองกำลัง`
5. `ผู้บัญชาการ`

ห้าม:

* เปลี่ยนทุกตำแหน่งเป็น `ผู้บัญชาการ`
* ใช้ `ผู้บัญชาการกองกำลัง` เมื่อแหล่งเดิมระบุเพียง `commander`
* ใช้ `หัวหน้าหมวด` แทน `หัวหน้าหมู่`
* สรุประดับหน่วยจากชื่อบุคคลเพียงอย่างเดียว

## Magic Corps commander / manager

แหล่งเดิมให้รูปอังกฤษสองหน้าที่:

* `commander`
* `manager`

รูปไทยปัจจุบัน:

`ผู้ดูแลกองเวท`

ระหว่างรอตรวจ:

* ใช้รูปไทยตามบริบท
* ห้ามยืนยันว่าเป็นผู้บัญชาการทหารเต็มรูปแบบ
* ห้ามยืนยันว่าเป็นเจ้าหน้าที่ธุรการ
* รักษารูปอังกฤษทั้งสอง
* บันทึกหลักฐานใหม่ใน `../90_รอตรวจ/ข้อมูลขัดแย้ง.md`

## กฎ

ใช้ `ต้นหน` เมื่อ:

* บุคคลทำหน้าที่เกี่ยวกับเส้นทางหรือการเดินเรือ

* ตำแหน่งทำหน้าที่เป็นสมาชิกประจำเรือ

ห้ามใช้ `ต้นหน` เมื่อ `navigator` หมายถึง:

* ผู้ใช้ระบบนำทางทั่วไป
* ผู้นำทางบนบก
* เครื่องมือหรือระบบนำทาง
* บุคคลที่เพียงบอกทิศทางครั้งเดียว

# บทบาทการต่อสู้ไม่ใช่คลาสโดยอัตโนมัติ

รายการต่อไปนี้เป็นบทบาทตามหน้าที่:

* ตัวทำความเสียหาย
* ตัวรับการโจมตี
* ผู้ยืนแนวหน้า
* ผู้ใช้ความสามารถสายสนับสนุน
* ตัวล่อ
* ผู้ลาดตระเวน

ห้ามสรุปว่า:

* ระบบกำหนดคลาสเหล่านี้อย่างเป็นทางการ
* ทุกทีมต้องมีทุกบทบาท
* บุคคลหนึ่งทำได้เพียงบทบาทเดียว
* บทบาทให้โบนัสค่าสถานะ
* ตัวรับการโจมตีมีระบบค่าคุกคาม
* ตัวทำความเสียหายต้องอยู่แนวหลัง
* ผู้ใช้ความสามารถสายสนับสนุนไม่สามารถต่อสู้โดยตรง

รายละเอียดวิธีจัดทีมของตัวละครให้ยึด:

`../04_เกม/กลไก/ระบบการต่อสู้.md`

# วิธีเพิ่มตำแหน่งหรือบทบาทใหม่

ใช้รูปแบบ:

```md
| ID | อังกฤษหลัก | ไทยหลัก | รูปอังกฤษอื่น | ประเภท | วิธีสร้างคำ | สถานะ | หมายเหตุ |
```

ข้อมูลที่ต้องมี:

* คำต้นฉบับ
* คำไทยเสนอ
* ประเภท
* วิธีสร้างคำ
* รูปอังกฤษอื่น
* รูปไทยอื่น
* บริบทที่ยืนยันหน้าที่
* จุดที่ปรากฏครั้งแรก
* สังกัดเมื่อจำเป็นต่อการแยกความหมาย
* หลักฐาน
* สถานะ

## การสร้าง ID

ใช้คำนำหน้าตามประเภท:

| ประเภท | คำนำหน้า |
| ------------- | -------- |
| ตำแหน่งหรือยศ | `title.` |
| ระดับ | `rank.` |
| บทบาท | `role.` |

ตัวอย่าง:

```text
title.lord
title.corps_commander
rank.explorer_6
role.team_leader
role.tank
```

## ก่อนเพิ่มรายการ

ตรวจว่า:

1. เป็นตำแหน่ง ยศ บทบาท องค์กร หรือชื่อบุคคล
2. มีรายการเดียวกันอยู่แล้วหรือไม่
3. รูปอังกฤษต่างกันหมายถึงตำแหน่งเดียวกันหรือไม่
4. เป็นตำแหน่งทางการหรือคำอธิบายตามหน้าที่
5. ระดับหน่วยหรืออำนาจได้รับการยืนยันหรือไม่
6. เป็นบทบาทการต่อสู้หรือคลาสของระบบ
7. คำไทยเพิ่มระดับอำนาจที่ต้นฉบับไม่ได้ระบุหรือไม่
8. ต้องส่งไป `../90_รอตรวจ/ชื่อรอตรวจ.md` ก่อนหรือไม่
9. มีข้อมูลขัดแย้งที่ต้องส่งไป `../90_รอตรวจ/ข้อมูลขัดแย้ง.md` หรือไม่
