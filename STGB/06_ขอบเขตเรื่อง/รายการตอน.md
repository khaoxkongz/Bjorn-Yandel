# STGB — รายการตอน

## จุดประสงค์

เอกสารนี้เป็นทะเบียนขอบเขตตอนและชื่อบทย่อยที่ได้รับการยืนยันในโครงการ

ใช้เพื่อ:

* ตรวจว่าฐานข้อมูลครอบคลุมถึงตอนใด
* ตรวจชื่อบทย่อยของแต่ละช่วง
* จำกัดการใช้ข้อมูลตามลำดับเรื่อง
* เชื่อมข้อมูลเสียง ตัวละคร ศัพท์ และกลไกเข้ากับช่วงตอน
* ป้องกันการนำข้อมูลจากช่วงหลังไปใช้ย้อนหลัง
* ตรวจความต่อเนื่องเมื่อเพิ่มตอนใหม่
* บันทึกจุดที่ช่วงตอนกับเลขบทย่อยยังขัดกัน

เอกสารนี้ไม่ใช่:

* สรุปเนื้อเรื่องรายตอน
* รายการเหตุการณ์สำคัญ
* รายชื่อตัวละครที่ปรากฏ
* ลำดับฉาก
* บันทึกการแปล
* ประวัติการแก้ต้นฉบับหรือบทแปล

## กฎสำคัญ

* ข้อมูลที่ระบุว่าเริ่มใช้ในช่วงหนึ่ง ห้ามนำไปใช้กับช่วงก่อนหน้าโดยอัตโนมัติ
* การอยู่ในช่วงตอนเดียวกันไม่ได้หมายความว่าข้อมูลปรากฏในทุกตอนของช่วงนั้น
* ห้ามแบ่งช่วงออกเป็นรายตอนจากการคาดเดา
* ห้ามย้ายเส้นแบ่งระหว่างบทย่อยโดยไม่มีหลักฐาน
* ห้ามแก้เลขตอนเพื่อทำให้จำนวนตอนตรงกับเลขบทย่อยโดยอัตโนมัติ
* หากตารางหลักขัดกับประวัติรุ่น ให้เก็บข้อมูลทั้งสองและส่งไปตรวจ
* ชื่อบทย่อยต้องรักษารูปที่ดัชนีเดิมกำหนด
* การเพิ่มตอนใหม่ต้องต่อจากขอบเขตล่าสุดโดยไม่สร้างช่องว่างหรือเลขซ้ำ

# การใช้งานร่วมกับไฟล์อื่น

## เสียงตัวละคร

ข้อมูลเสียงที่กำหนดว่าเริ่มใช้ตั้งแต่บทย่อยหนึ่ง ให้ตรวจช่วงจากไฟล์นี้ก่อน

ตัวอย่างรูปแบบการอ้างอิง:

```text
เริ่มใช้ตั้งแต่ episode_range.373_376
```

ห้ามใช้คุณลักษณะเสียงย้อนหลังเพียงเพราะตัวละครเดียวกันปรากฏก่อนหน้านั้น

## ตัวละคร

ทะเบียนการปรากฏแบบช่วงให้ยึด:

`../03_ตัวละคร/การปรากฏตามตอน.md`

การมีชื่อตัวละครในช่วงหนึ่งไม่ได้ยืนยันตอนย่อยที่แน่นอนภายในช่วง

## ศัพท์และกลไก

เมื่อบันทึกจุดปรากฏครั้งแรก ให้ระบุ:

* เลขตอน หากยืนยันได้
* ID ช่วงตอน หากทราบเพียงช่วง
* ชื่อบทย่อย
* สถานะความแม่นยำของข้อมูล

ตัวอย่าง:

```text
first_seen_range: episode_range.391_395
first_seen_episode: unknown
```

## กฎ

* ห้ามยกระดับ `ช่วงยืนยัน` เป็น `ตอนยืนยัน`
* ห้ามเลือกตอนแรกของช่วงเป็นจุดปรากฏครั้งแรกโดยอัตโนมัติ
* ห้ามเลือกตอนสุดท้ายของช่วงเป็นจุดปรากฏล่าสุดโดยอัตโนมัติ
* ห้ามใช้ชื่อบทย่อยเพียงอย่างเดียวแทนเลขตอนเมื่อมีความคลุมเครือ

---

# วิธีเพิ่มช่วงตอนใหม่

ใช้รูปแบบ:

```md
| ID | ช่วงตอน | จำนวนเลขตอน | ชื่อบทย่อย | ช่วงเลขบทย่อย | สถานะ | หมายเหตุ |
```

ข้อมูลที่ต้องมี:

* ตอนเริ่มต้น
* ตอนสิ้นสุด
* ชื่อบทย่อย
* เลขบทย่อยแรกและสุดท้าย
* แหล่งหลักฐาน
* วันที่เพิ่ม
* สถานะการตรวจ
* หมายเหตุเกี่ยวกับเส้นแบ่ง

## การสร้าง ID

ใช้รูปแบบ:

```text
episode_range.<ตอนเริ่มต้น>_<ตอนสิ้นสุด>
```

ตัวอย่าง:

```text
episode_range.391_395
episode_range.396_400
```

## ขั้นตอน

1. ตรวจตอนล่าสุดใน frontmatter
2. ตรวจว่าช่วงใหม่เริ่มต่อจากตอนล่าสุด
3. ตรวจว่าไม่มีเลขตอนซ้ำ
4. ตรวจว่าไม่มีช่องว่าง
5. ตรวจจำนวนเลขตอนกับช่วงเลขบทย่อย
6. ตรวจชื่อบทย่อยจากแหล่งหลัก
7. เพิ่มรายการในทะเบียนหลัก
8. ปรับ `covered_through_episode`
9. ปรับ `covered_through_section`
10. ปรับ `manifest.yaml`
11. ปรับ `00_ดัชนี.md`
12. บันทึกใน `CHANGELOG.md`

# วิธีแก้เส้นแบ่งช่วงเดิม

การแก้ช่วงตอนต้องมี:

* ช่วงเดิม
* ช่วงใหม่
* หลักฐาน
* เหตุผล
* รายการไฟล์ที่ได้รับผลกระทบ
* วันที่แก้
* ผู้ตรวจ
* สถานะการยืนยัน

ไฟล์ที่ต้องตรวจผลกระทบอย่างน้อย:

* `../03_ตัวละคร/การปรากฏตามตอน.md`
* `บริบทช่วงปัจจุบัน.md`
* ไฟล์เสียงที่กำหนดพัฒนาการตามบทย่อย
* ทะเบียนศัพท์ที่บันทึกจุดปรากฏครั้งแรก
* ทะเบียนสกิล ไอเทม และมอนสเตอร์
* `00_ดัชนี.md`
* `manifest.yaml`
* `CHANGELOG.md`

ห้ามเปลี่ยนช่วงในไฟล์นี้เพียงไฟล์เดียว
