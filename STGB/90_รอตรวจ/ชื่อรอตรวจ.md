# STGB — ชื่อรอตรวจ

## จุดประสงค์

เอกสารนี้เป็นคิวกลางสำหรับชื่อที่แหล่งข้อมูลเดิมระบุอย่างชัดเจนว่า:

* รอตรวจชื่อ
* รอตรวจต้นฉบับ
* รอตรวจรูปชื่อ
* รอตรวจรูปต้นฉบับ
* รอตรวจชื่อทางการ
* รอตรวจความสัมพันธ์ระหว่างรูปชื่อ

ใช้เพื่อ:

* รักษารูปที่ใช้อยู่ระหว่างรอตรวจ
* ระบุปัญหาของแต่ละชื่อ
* ระบุหลักฐานที่ต้องหา
* ป้องกันการแก้ชื่อด้วยการคาดเดา
* ติดตามผลการตรวจสอบ
* ส่งชื่อที่ตรวจเสร็จกลับไปยังทะเบียนหลัก
* บันทึกผลกระทบต่อไฟล์อื่น

เอกสารนี้ไม่ใช่:

* รายการชื่อชั่วคราวทั้งหมด
* รายการข้อมูลขัดแย้งทุกประเภท
* พื้นที่เสนอชื่อใหม่
* พจนานุกรมชื่อหลัก
* บันทึกการแก้คำที่เสร็จสมบูรณ์แล้ว

---

# ขอบเขตของคิว

รายการจะเข้าคิวนี้เมื่อ:

1. ไฟล์ต้นทางระบุสถานะเกี่ยวกับการตรวจชื่อโดยตรง
2. ต้องตรวจรูปสะกดจากต้นฉบับ
3. ต้องตรวจว่ารูปอังกฤษหลายรูปเป็นชื่อเดียวกันหรือไม่
4. ต้องตรวจว่าคำแปลปัจจุบันตรงกับชื่อทางการหรือไม่
5. ต้องตรวจว่ารูปหนึ่งเป็นชื่อเฉพาะ ชื่อประเภท หรือคำบรรยาย
6. ความสัมพันธ์ระหว่างชื่ออาจกระทบการเลือกชื่อไทย

รายการไม่เข้าคิวนี้เพียงเพราะมีสถานะ `ชั่วคราว`

ชื่อชั่วคราวให้คงอยู่ในทะเบียนหลัก เว้นแต่มีเหตุให้ตรวจเฉพาะเจาะจง

# สถานะการตรวจ

| สถานะ | ความหมาย |
| ------------ | ------------------------------------------------- |
| รอตรวจ | อยู่ในคิว แต่ยังไม่ได้เริ่มตรวจ |
| รอหลักฐาน | ทราบปัญหาแล้ว แต่ยังไม่มีต้นฉบับหรือข้อมูลเพียงพอ |
| กำลังตรวจ | อยู่ระหว่างเปรียบเทียบแหล่งข้อมูล |
| เสนอผลตรวจ | มีข้อเสนอแล้ว แต่ยังไม่ได้อนุมัติ |
| ยืนยันแล้ว | ตรวจเสร็จและส่งผลกลับทะเบียนหลักแล้ว |
| คงรูปเดิม | ตรวจแล้วและยืนยันให้ใช้รูปเดิม |
| ยกเลิกรายการ | พบว่าไม่ใช่ปัญหาชื่อหรือเป็นรายการซ้ำ |
| ย้ายคิว | ปัญหาหลักเป็นข้อมูลขัดแย้งหรือข้อเสนอใหม่ |

## กฎ

* การมีข้อเสนอหนึ่งรูปไม่เท่ากับ `ยืนยันแล้ว`
* ห้ามลบรูปเดิมระหว่างรอตรวจ
* ห้ามเปลี่ยนทะเบียนหลักก่อนอนุมัติผลตรวจ
* เมื่อยืนยันแล้วต้องบันทึกหลักฐานและวันที่
* หากปัญหาไม่ใช่เรื่องชื่อ ให้ย้ายไปไฟล์ที่ถูกประเภท

# ตัวละคร

## Guardweaver Drowes, Draus

* Review ID: `review.name.character.guardweaver_drowes`
* ID ต้นทาง: `character.guardweaver_drowes`
* อังกฤษปัจจุบัน: `Guardweaver Drowes, Draus`
* ไทยปัจจุบัน: `การ์ดวีเวอร์ ดรอว์ส`
* สถานะเดิม: `รอตรวจชื่อ`
* สถานะคิว: `รอตรวจ`

### ประเด็น

รูปอังกฤษมีโครงสร้างที่อาจตีความได้หลายแบบ:

* `Guardweaver` อาจเป็นชื่อ ตำแหน่ง ฉายา หรือคำเรียกประเภท
* `Drowes` อาจเป็นชื่อหลัก
* `Draus` อาจเป็นรูปอื่นของชื่อเดียวกัน
* เครื่องหมายจุลภาคอาจแยกชื่อออกจากตำแหน่ง หรืออาจเป็นการจัดรูปจากฉบับแฟนแปล

### รูปที่ใช้ระหว่างรอตรวจ

`การ์ดวีเวอร์ ดรอว์ส`

ห้ามเปลี่ยนเป็นรูปอื่นโดยไม่มีหลักฐาน

### หลักฐานที่ต้องหา

* ข้อความต้นฉบับจุดปรากฏครั้งแรก
* รูปภาษาอังกฤษจากหลายตอน
* รูปภาษาเกาหลีเมื่อเข้าถึงได้
* บริบทที่บุคคลอื่นเรียกชื่อ
* บริบทที่ระบบหรือผู้บรรยายแนะนำตัว
* หลักฐานว่า `Guardweaver` เป็นตำแหน่งหรือชื่อ

### ห้าม

* แยกเป็นตัวละครสองคน
* ตัดคำว่า `Guardweaver`
* เปลี่ยน `Drowes` เป็น `Draus`
* แปล `Guardweaver` เชิงความหมาย
* สร้างตำแหน่งใหม่จากคำนี้
* แก้ชื่อในบทเก่าโดยยังไม่ยืนยันผลตรวจ

# รายการที่ไม่อยู่ในคิวชื่อ

## ชื่อชั่วคราวทั่วไป

สถานะ `ชั่วคราว` เพียงอย่างเดียวไม่ทำให้รายการเข้าสู่ไฟล์นี้

ชื่อชั่วคราวจะเข้าสู่คิวเมื่อ:

* พบรูปต้นฉบับที่น่าสงสัย
* พบรูปอังกฤษหลายแบบที่อาจเป็นคนละชื่อ
* มีเหตุว่าคำไทยอาจคลาดเคลื่อน
* ต้องตัดสินชื่อทางการ
* ทะเบียนหลักเปลี่ยนสถานะเป็นรอตรวจ

## ชื่อปลอมและตัวตนปลอม

รายการที่ระบุว่า `ชื่อปลอม` ให้เก็บสถานะใน:

`../03_ตัวละคร/ตัวตนและนามแฝง.md`

หรือทะเบียนเฉพาะของสิ่งนั้น

ไม่ต้องเข้าคิวชื่อ เว้นแต่รูปสะกดของชื่อปลอมเองมีปัญหา

## บุคคลที่ยังไม่เปิดเผยชื่อ

รายการประเภท:

* ไม่เปิดเผยชื่อ
* ฉายาชั่วคราว
* ยังระบุตัวไม่ชัด

ไม่ถือเป็นปัญหาการสะกดชื่อโดยอัตโนมัติ

ให้เก็บในทะเบียนตัวตนหรือ `ข้อมูลขัดแย้ง.md` ตามปัญหา

## ข้อมูลขัดแย้ง

ตัวอย่างปัญหาที่ต้องไป `ข้อมูลขัดแย้ง.md`:

* บุคคลหนึ่งมีสังกัดสององค์กร
* สองรายการใช้ชื่อไทยเดียวกัน
* ประเภทของสิ่งหนึ่งขัดกัน
* ช่วงตอนกับเลขบทย่อยไม่ตรงกัน
* หมายเลขไอเทมขัดกับประเภท
* รูปอังกฤษอาจหมายถึงคนละสิ่ง

ปัญหาสามารถอยู่ทั้งสองคิวได้เมื่อข้อขัดแย้งส่งผลต่อชื่อโดยตรง

## กฎเกี่ยวกับ ID

โดยทั่วไป การแก้ชื่อไทยไม่ควรเปลี่ยน ID

เปลี่ยน ID เฉพาะเมื่อ:

* พบว่าเป็นคนละรายการ
* ID เดิมอ้างสิ่งผิดประเภท
* รายการถูกแยกหรือรวม
* ชื่ออังกฤษหลักเดิมผิดจน ID ทำให้เข้าใจผิดอย่างมีนัยสำคัญ

การเปลี่ยน ID ต้องมีรายการเปลี่ยนทางหรือบันทึกการย้ายอย่างชัดเจน
