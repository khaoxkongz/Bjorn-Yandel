# STGB — ข้อมูลขัดแย้ง

## จุดประสงค์

เอกสารนี้เป็นทะเบียนกลางสำหรับข้อมูลที่แหล่งเดิมให้รายละเอียดต่างกันหรือไม่สามารถใช้ร่วมกันได้โดยตรง

ใช้เมื่อ:

* ช่วงตอนสองแหล่งไม่ตรงกัน
* จำนวนตอนกับจำนวนบทย่อยไม่ตรงกัน
* ตัวละครมีสังกัดมากกว่าหนึ่งรูป
* รูปอังกฤษหลายแบบอาจมีความหมายต่างกัน
* ประเภทของรายการขัดกัน
* สองรายการใช้ชื่อไทยเดียวกัน
* หมายเลขหรือชั้นของไอเทมไม่สอดคล้องกัน
* ยังไม่ทราบว่ารายการควรรวมหรือแยก
* ข้อมูลใหม่ไม่สอดคล้องกับทะเบียนเดิม

เอกสารนี้ใช้เพื่อ:

* รักษาข้อมูลทุกฝั่ง
* ระบุจุดที่ขัดกันอย่างชัดเจน
* ห้ามการเลือกข้อมูลฝั่งใดฝั่งหนึ่งโดยไม่มีหลักฐาน
* ระบุผลกระทบต่อไฟล์อื่น
* ติดตามสถานะการตรวจ
* บันทึกผลการตัดสินเมื่อมีหลักฐานเพียงพอ

เอกสารนี้ไม่ใช่:

* คิวตรวจชื่อทั้งหมด
* รายการข้อมูลที่เพียงยังไม่ทราบ
* พื้นที่เสนอคำใหม่
* พื้นที่แก้ข้อมูลให้สอดคล้องกันด้วยการคาดเดา
* บันทึกความคิดเห็นส่วนตัวของผู้แปล

# นิยามข้อมูลขัดแย้ง

## ถือว่าขัดแย้งเมื่อ

มีข้อมูลอย่างน้อยสองชุดที่ไม่สามารถเป็นจริงพร้อมกันได้โดยง่าย เช่น:

* ช่วงตอนสิ้นสุดคนละเลข
* รายการเดียวถูกจัดเป็นคนละประเภท
* บุคคลเดียวมีสังกัดคนละองค์กรในบริบทเดียวกัน
* ชื่ออังกฤษสองชื่อถูกบันทึกเป็นรายการเดียว แต่ความหมายอาจต่างกัน
* หมายเลขไอเทมไม่ตรงกับประเภทที่ข้อความเรียก
* สองรายการต่างกันใช้คำไทยเดียวกัน

## ยังไม่ถือว่าขัดแย้งเมื่อ

* ข้อมูลเพียงขาดหาย
* ยังไม่ทราบรายละเอียด
* รูปแปลมีสถานะชั่วคราว
* ตัวละครเปลี่ยนสังกัดได้ตามลำดับเรื่อง
* คำหนึ่งมีหลายความหมายตามบริบท
* ชื่อหนึ่งมีรูปสะกดอื่นที่ได้รับการบันทึกไว้แล้ว
* ข้อมูลสองชุดกล่าวถึงคนละช่วงเวลา
* คำอธิบายสองแบบสามารถจริงพร้อมกันได้

ก่อนสร้างรายการต้องตรวจว่า ความแตกต่างเกิดจากเวลา บริบท หรือระดับรายละเอียดหรือไม่

# สถานะข้อขัดแย้ง

| สถานะ | ความหมาย |
| ---------------- | ---------------------------------------------- |
| เปิด | ยืนยันว่ามีข้อมูลขัดแย้ง แต่ยังไม่ได้ตรวจ |
| รอหลักฐาน | ระบุสิ่งที่ต้องตรวจแล้ว แต่ยังไม่มีข้อมูล |
| กำลังตรวจ | อยู่ระหว่างเปรียบเทียบแหล่ง |

| ไม่ใช่ข้อขัดแย้ง | พบว่าเป็นคนละเวลา คนละบริบท หรืออยู่ร่วมกันได้ |

* ห้ามเปลี่ยนสถานะเป็น `ยุติแล้ว` จากการลงคะแนนหรือความรู้สึก

* เมื่อยุติแล้วต้องระบุหลักฐานและไฟล์ที่แก้
* ห้ามลบข้อมูลเดิมออกจากประวัติ

## การสร้าง Conflict ID

ใช้รูปแบบ:

```text id="oxt9dx"
conflict.<หมวด>.<ชื่อปัญหา>
```

หมวดที่ใช้ได้ เช่น:

* `episode`
* `character`
* `org`
* `location`
* `skill`
* `item`
* `monster`
* `stat`
* `context`
* `voice`

ตัวอย่าง:

```text id="t6t3n2"
conflict.character.jun_affiliation
conflict.item.no_1911_number_class
conflict.context.scout
```

# การยุติข้อขัดแย้ง

ผลที่อนุญาต:

| ผล | ใช้เมื่อ |
| ---------------------- | ------------------------------------- |
| เลือกข้อมูลชุดที่หนึ่ง | หลักฐานยืนยันฝั่งหนึ่ง |
| เลือกข้อมูลชุดที่สอง | หลักฐานยืนยันอีกฝั่ง |
| รวมข้อมูล | ทั้งสองเป็นส่วนของข้อเท็จจริงเดียวกัน |
| แยกรายการ | ข้อมูลกล่าวถึงคนละสิ่ง |
| แยกตามช่วงเวลา | ทั้งสองถูกต้องแต่คนละเวลา |
| แยกตามบริบท | ทั้งสองถูกต้องแต่หน้าที่ต่างกัน |
| คงความคลุมเครือ | หลักฐานยังไม่พอ |
| ยกเลิกข้อขัดแย้ง | พบว่าไม่ขัดกันจริง |
