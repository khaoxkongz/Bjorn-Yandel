# STGB — ตัวตนและนามแฝง

## จุดประสงค์

เอกสารนี้เก็บชื่อหรือตัวตนที่บุคคลใช้แทนชื่อหลัก ได้แก่

* ตัวตนที่ใช้ในร่างอื่น
* รูปลักษณ์หรือบทบาทเฉพาะ
* นามแฝง
* ชื่อปลอม
* ชื่อผู้ใช้
* หน้ากาก
* ฉายา
* ชื่อเล่น
* ตำแหน่งที่ใช้แทนชื่อจริง
* ชื่อเรียกของบุคคลที่ยังไม่เปิดเผยชื่อ

ชื่อบุคคลหลักให้เก็บใน:

`ตัวละคร.md`

กฎเสียงของตัวตนหรือหน้ากากให้เก็บใน:

`../02_เสียง/`

## กฎการจัดเก็บ

1. ตัวตนหนึ่งรายการมีหนึ่ง ID
2. ต้องเชื่อมกับ `character_id` ของเจ้าของเมื่อทราบ
3. หากยังไม่ทราบเจ้าของ ให้ใช้ `ไม่ทราบ`
4. ห้ามสร้างบุคคลใหม่เพียงเพราะพบชื่อปลอมหรือหน้ากาก
5. ประเภทของชื่อและสถานะข้อมูลต้องแยกออกจากกัน
6. ชื่อที่มีหลายรูปสะกดให้รวมไว้ในรายการเดียว
7. ห้ามสรุปว่าฉายาหนึ่งเป็นชื่อจริงโดยไม่มีหลักฐาน
8. เมื่อเปิดเผยเจ้าของตัวตน ให้แก้รายการเดิมแทนการสร้างรายการซ้ำ

# วิธีเพิ่มตัวตนใหม่

ใช้รูปแบบ:

```md
| ID | อังกฤษ | ไทย | รูปอังกฤษอื่น | ประเภท | เจ้าของ | สถานะ | ช่วงอ้างอิง | หมายเหตุ |
```

## กฎการสร้าง ID

ใช้คำนำหน้าตามประเภท:

| ประเภท | คำนำหน้า |
| ---------------- | ----------- |
| ตัวตนหรือหน้ากาก | `identity.` |
| นามแฝงหรือฉายา | `alias.` |
| ชื่อผู้ใช้ | `username.` |
| ชื่อเล่น | `nickname.` |

ตัวอย่าง:

```text
identity.rihen_schuiz
identity.lion_mask
alias.blood_knight
username.hs123
nickname.penny
```

## ก่อนเพิ่มรายการ

ตรวจว่า:

1. ชื่อนี้เป็นบุคคลใหม่หรือชื่ออื่นของบุคคลเดิม
2. ทราบเจ้าของตัวตนหรือไม่
3. เป็นชื่อปลอม นามแฝง หน้ากาก ฉายา หรือชื่อผู้ใช้
4. มีรูปสะกดอื่นหรือไม่
5. มีรายการเดียวกันอยู่แล้วหรือไม่
6. ต้องเพิ่มกฎเสียงใน `02_เสียง` หรือไม่
7. มีข้อมูลขัดแย้งที่ต้องส่งไป `90_รอตรวจ` หรือไม่

## เมื่อยังไม่แน่ใจ

* ใช้ประเภท `รอตรวจประเภท`
* ใช้เจ้าของ `ไม่ทราบ`
* ใช้สถานะ `รอตรวจ`
* ห้ามคาดเดาเจ้าของจากบริบทที่ไม่ยืนยัน
* เพิ่มประเด็นใน `90_รอตรวจ/ชื่อรอตรวจ.md`
