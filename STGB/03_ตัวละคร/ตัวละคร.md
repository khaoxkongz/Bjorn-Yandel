# STGB — ตัวละคร

## จุดประสงค์

เอกสารนี้เป็นทะเบียนบุคคลหลักของโครงการ

ให้เก็บ:

- รหัสตัวละคร
- ชื่ออังกฤษหลัก
- ชื่อไทยหลัก
- รูปสะกดอังกฤษอื่น
- ประเภทของบุคคล
- สถานะชื่อ
- บทบาทหรือหมายเหตุสั้น
- ช่วงตอนที่มีรายการอ้างอิงในฐานข้อมูลเดิม

ไม่ให้เก็บ:

- โปรไฟล์เสียง
- สรรพนามและคำเรียก
- ประวัติเนื้อเรื่อง
- เป้าหมายหรือสถานที่ปัจจุบัน
- นามแฝง
- ชื่อปลอม
- ชื่อผู้ใช้
- หน้ากาก
- ฉายาที่ไม่ได้ใช้เป็นทะเบียนบุคคล
- รายการปรากฏทุกตอน

ข้อมูลตัวตน นามแฝง ชื่อปลอม ชื่อผู้ใช้ และฉายาให้เก็บใน:

`ตัวตนและนามแฝง.md`

ข้อมูลการปรากฏตามช่วงตอนให้เก็บใน:

`การปรากฏตามตอน.md`

## กฎการจัดเก็บ

1. หนึ่งบุคคลมีหนึ่งแถว
2. รูปสะกดอังกฤษหลายแบบให้รวมไว้ในแถวเดียว
3. ห้ามสร้างแถวใหม่เพียงเพราะบุคคลใช้ชื่อปลอมหรือหน้ากาก
4. ตำแหน่ง อาชีพ และบทบาทต้องอยู่ในช่อง `หมายเหตุ` ไม่ใช่ช่องสถานะ
5. บุคคลที่ไม่เปิดเผยชื่อให้ใช้ประเภท `บุคคลไม่เปิดเผยชื่อ`
6. หากยังไม่แน่ใจว่าชื่อหนึ่งเป็นบุคคลหรือฉายา ให้รักษารายการเดิมไว้ชั่วคราวและเพิ่มหมายเหตุ
7. ห้ามเปลี่ยนชื่อมาตรฐานหรือชื่อบังคับโดยอัตโนมัติ

## รายการที่ต้องระวัง

### ชื่อที่อาจเป็นฉายา

รายการต่อไปนี้ยังเก็บไว้ในทะเบียนบุคคลตามการจัดประเภทของไฟล์เดิม แต่ควรย้ายไป `ตัวตนและนามแฝง.md` หากมีหลักฐานว่าเป็นฉายาหรือชื่อเรียกแทนบุคคล:

- แม่มดแห่งปฐพี
- ประมุขแห่งออร์คิวลิส
- เขี้ยวเหล็ก
- กำแพงเหล็ก
- เพลิงอสนี

### บุคคลไม่เปิดเผยชื่อ

รายการต่อไปนี้เป็นบุคคลจริงในเรื่อง แต่ยังใช้ตำแหน่งหรือฉายาแทนชื่อ:

- เจ้าเมืองโนอาร์กในอดีต
- อัศวินโลหิต
- ผู้เฝ้าประภาคาร

เมื่อเปิดเผยชื่อจริงในภายหลัง:

1. ห้ามสร้างตัวละครใหม่ทันที
2. ให้ตรวจว่าเป็นบุคคลเดียวกันหรือไม่
3. อัปเดตแถวเดิมด้วยชื่อจริง
4. ย้ายตำแหน่งหรือฉายาเดิมไป `ตัวตนและนามแฝง.md`
5. บันทึกการเปลี่ยนแปลงใน `CHANGELOG.md`

## วิธีเพิ่มตัวละครใหม่

เมื่อพบตัวละครใหม่ ให้เพิ่มข้อมูลอย่างน้อย:

```md
| ID | อังกฤษหลัก | ไทยหลัก | รูปอังกฤษอื่น | ประเภท | สถานะ | ช่วงอ้างอิงในฐานเดิม | หมายเหตุ |
```

กฎการสร้าง ID:

- ใช้อักษรอังกฤษตัวเล็ก
- ใช้ `_` คั่นคำ
- เริ่มด้วย `char.`
- ห้ามใช้ตำแหน่งปัจจุบันเป็น ID หากทราบชื่อบุคคลแล้ว
- เมื่อกำหนด ID แล้วไม่ควรเปลี่ยน แม้ภายหลังจะเปลี่ยนชื่อมาตรฐาน

ตัวอย่าง:

```text
char.lee_hansoo
char.amelia_rainweilz
char.jun_arsene
char.unknown_blood_knight
```

## การตรวจสอบก่อนบันทึก

ก่อนเพิ่มหรือแก้รายการ ให้ตรวจว่า:

1. บุคคลนี้มีอยู่ในทะเบียนแล้วหรือไม่
2. ชื่อใหม่เป็นชื่อจริง นามแฝง ฉายา หรือชื่อผู้ใช้
3. รูปสะกดต่างกันเป็นบุคคลเดียวกันหรือไม่
4. ประเภทและบทบาทถูกแยกออกจากสถานะแล้วหรือไม่
5. มีข้อมูลขัดแย้งที่ต้องส่งไป `90_รอตรวจ/ข้อมูลขัดแย้ง.md` หรือไม่
6. การแก้ชื่อมาตรฐานต้องบันทึกใน `CHANGELOG.md` หรือไม่
