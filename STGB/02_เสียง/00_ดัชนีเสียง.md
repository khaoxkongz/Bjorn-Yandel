# STGB — ดัชนีเสียง

## จุดประสงค์

เอกสารนี้ใช้เป็นดัชนีสำหรับค้นหากฎเสียงบรรยายและเสียงตัวละคร

ไฟล์ในหมวด `02_เสียง` ให้เก็บเฉพาะข้อมูลที่ส่งผลต่อการถ่ายทอดผ่านภาษา ได้แก่

- น้ำเสียงและระดับภาษา
- สรรพนามและคำเรียก
- จังหวะการพูดและการคิด
- บุคลิกที่ส่งผลต่อการเลือกคำ
- วิธีแสดงหรือเก็บอารมณ์
- วิธีพูดกับบุคคลต่างประเภท
- ความสัมพันธ์ที่ส่งผลต่อภาษา
- พัฒนาการที่ทำให้รูปแบบการพูดเปลี่ยน
- จุดที่ต้องระวังไม่ให้บุคลิกเคลื่อน

## ข้อมูลที่ไม่ควรเก็บในหมวดนี้

- สถานที่ปัจจุบัน
- เป้าหมายปัจจุบัน
- เหตุการณ์ที่เพิ่งเกิด
- สิ่งที่ตัวละครเพิ่งค้นพบ
- ความลับหรือข้อมูลที่ตัวละครรู้
- สถานะของแผนการ
- รายละเอียดเนื้อเรื่องที่ไม่ส่งผลต่อภาษา
- ชื่อตัวละครและนามแฝงฉบับมาตรฐาน
- กลไกสกิลหรือค่าสถานะ

ข้อมูลเหล่านี้ให้เก็บในไฟล์เจ้าของข้อมูลที่กำหนดใน `manifest.yaml`

## โครงสร้างของอีฮันซูและบยอร์น

ข้อมูลของอีฮันซูและบยอร์นแบ่งเป็นห้าไฟล์:

| ไฟล์ | หน้าที่ |
| -------------------- | ---------------------------------------------------------- |
| `แก่นเสียง.md` | แก่นบุคลิก ความคิดในใจ เสียงพื้นฐาน และข้อควรระวัง |
| `ตัวตนและหน้ากาก.md` | บยอร์น รีเฮน อีฮันซูในรูปลักษณ์เดิม และหน้ากากต่าง ๆ |
| `ความสัมพันธ์.md` | วิธีพูดกับบุคคลสำคัญ |
| `พัฒนาการ.md` | การเปลี่ยนแปลงตามช่วงเรื่องที่ห้ามใช้ย้อนหลัง |
| `สถานการณ์.md` | วิธีพูดและคิดในเงื่อนไขเฉพาะ เช่น ต่อสู้ โกรธ หรือหวาดกลัว |

ก่อนแปลฉากของอีฮันซู ให้เปิดอย่างน้อย:

1. `แก่นเสียง.md`
2. `ตัวตนและหน้ากาก.md` หากกำลังใช้ตัวตนอื่น
3. `ความสัมพันธ์.md` หากคู่สนทนามีกฎเฉพาะ
4. `พัฒนาการ.md` หากต้องตรวจระดับความสัมพันธ์ตามช่วงเวลา
5. `สถานการณ์.md` หากฉากตรงกับเงื่อนไขเฉพาะ

## การเลือกว่าใครควรมีไฟล์เฉพาะ

สร้างไฟล์เฉพาะเมื่อตัวละครมีอย่างน้อยหนึ่งเงื่อนไขต่อไปนี้:

- มีข้อมูลเสียงจำนวนมาก
- มีสรรพนามหรือคำเรียกเฉพาะ
- มีหลายตัวตนหรือหลายหน้ากาก
- มีพัฒนาการตามช่วงเรื่อง
- มีวิธีพูดแตกต่างกันชัดเจนตามคู่สนทนา
- ปรากฏบ่อยและมีความเสี่ยงที่เสียงจะไม่สม่ำเสมอ

หากข้อมูลยังสั้น ให้เก็บในไฟล์กลุ่มก่อน

## วิธีเพิ่มตัวละครใหม่

1. เพิ่มชื่อตัวละครใน `03_ตัวละคร/ตัวละคร.md`
2. เพิ่มข้อมูลเสียงเบื้องต้นในไฟล์กลุ่มที่เหมาะสม
3. ระบุขอบเขตตอนและสถานะของข้อมูล
4. แยกข้อเท็จจริงออกจากการอนุมาน
5. เมื่อข้อมูลมากพอ จึงย้ายไปเป็นไฟล์เฉพาะ
6. อัปเดตดัชนีนี้เมื่อสร้างหรือย้ายไฟล์

## กฎการใช้งาน

- กฎแก่นคงที่ใช้เป็นค่าปริยายของตัวละคร
- กฎตามคู่สนทนาใช้เมื่อคู่สนทนาตรงกัน
- กฎเฉพาะสถานการณ์ใช้เมื่อบริบทต้นฉบับรองรับ
- กฎพัฒนาการต้องตรวจช่วงตอนก่อนใช้
- ห้ามนำพัฒนาการช่วงหลังไปใช้ย้อนหลัง
- เมื่อกฎหลายประเภทเกี่ยวข้อง ให้ยึดลำดับดังนี้:

1. ตัวตนหรือหน้ากากที่กำลังใช้
2. ขอบเขตช่วงเรื่อง
3. คู่สนทนา
4. สถานการณ์เฉพาะ
5. แก่นเสียงทั่วไป
